# GPT 구독 후 모델·에포트 선택법 인스타툰 콘티

원문: https://newtypel.com/blog/2026-09-11-codex-effort-model-optimization-guide/

## 전체 흐름

GPT 구독 → 모델과 에포트 발견 → 무조건 최고 설정 선택 → 느리고 복잡해진 결과 → 오버씽킹 이해 → 목적과 범위에 맞춘 설정 → 빠른 답변과 토큰 절약

## 1장 — 구독했는데, 뭘 골라야 하지?

- 장 역할: 독자의 질문
- 핵심 의미: GPT를 구독한 초보자는 여러 모델과 에포트 단계 앞에서 무엇을 선택해야 할지 막막하다.
- 감정: 기대 → 고민
- 장면: 행동가가 GPT 구독 완료 화면을 보고 신나 한다. 곧이어 모델과 Effort 선택창을 발견하고 고개를 갸웃한다. 안내자와 분석가가 뒤에서 화면을 함께 본다.
- 정확한 문구:
  - 행동가: “GPT 구독 완료!”
  - 행동가: “모델과 Effort는 뭐지?”
  - 행동가: “제일 높은 게 좋겠지?”
- 화면 정보: 여러 모델 카드와 Low·Medium·High·Max 선택 버튼

## 2장 — 새 모델이니까 Max가 최고겠지?

- 장 역할: 문제 발생
- 핵심 의미: 최고난도 작업용 Astra에 Max 에포트까지 선택하면 단순 작업에는 필요한 것보다 많은 추론 자원과 대기 시간이 들어갈 수 있다.
- 감정: 자신감 → 당황
- 장면: 상단에서 행동가가 새로 나온 최고 성능 모델이라는 말을 듣고 `Astra + Max`를 힘차게 선택한다. 하단에서는 토큰 배터리 게이지가 빠르게 줄어드는 연출과 계속 돌아가는 대기 표시를 번갈아 본다. 요청 카드는 “버튼 색 바꾸기”처럼 아주 작게 보여준다.
- 정확한 문구:
  - 행동가: “Astra가 새로 나왔다고?”
  - 행동가: “그럼 Astra + Max!”
  - 행동가: “어… 아직 생각 중이네?”
  - 행동가: “단순한 작업인데 토큰을 이렇게 많이 써?”
- 화면 정보: 작은 요청 / 깊은 추론 / 길어진 대기
- 사실 표현 주의: 사용량이 반드시 즉시 소진되거나 제한 대기가 발생한다고 단정하지 않는다. 화면의 토큰 감소는 높은 에포트가 더 많은 추론 자원을 사용할 수 있음을 보여주는 비유적 연출로 사용한다.

## 3장 — 많이 생각하면 무조건 좋은 걸까?

- 장 역할: 원인 설명
- 핵심 의미: Effort는 AI가 답하기 전에 사용하는 생각의 깊이와 자원이다. Astra 자체가 오버씽킹하는 모델은 아니지만, 단순하고 범위가 좁은 작업에 Max를 고정하면 필요 이상의 분석과 검증이 붙을 수 있다.
- 감정: 혼란 → 이해
- 장면: 안내자가 작은 버튼 하나를 고치는 작업을 보여준다. 반대편에서는 AI를 상징하는 생각 구름이 드물게 일어날 예외와 먼 미래의 문제까지 계속 만들어낸다. 분석가가 불필요한 생각 구름을 잘라낸다.
- 정확한 문구:
  - 안내자: “Effort는 생각의 깊이야.”
  - 행동가: “깊을수록 좋은 거 아냐?”
  - 분석가: “Astra가 문제인 건 아냐.”
  - 안내자: “쉬운 일에 Max가 과한 거지.”
- 화면 정보: 오버씽킹 = 작업 범위를 넘어 필요 이상의 가능성까지 고민하는 것

## 4장 — 목적과 범위에 맞춰 고르자

- 장 역할: 선택 기준
- 핵심 의미: 모델과 Effort는 서열이 아니라 작업 목적, 난이도, 수정 범위에 맞춰 선택해야 한다.
- 감정: 막막함 → 판단 가능
- 장면: 분석가가 세 갈래 작업 카드를 펼친다. 행동가는 자신의 작업 카드를 적절한 설정 위에 놓는다. 안내자가 작은 작업부터 가볍게 시작하라고 안내한다.
- 정확한 문구:
  - 분석가: “최고보다 적합한 설정!”
  - 안내자: “목적과 범위를 먼저 봐.”
  - 행동가: “작게 시작하면 되는구나!”
- 화면 정보:
  - 단순 반복 → 가벼운 모델
  - 일반 작업 → 균형형 모델
  - 복잡한 난제 → 고성능 모델
  - 막힐 때만 Effort 한 단계 올리기

## 5장 — 가볍게 시작하고, 필요할 때만 올리기

- 장 역할: 해결 방법과 결론
- 핵심 의미: 낮거나 중간 설정으로 빠르게 시도하고 부족할 때만 한 단계 올리면 토큰을 아끼면서 답변 속도와 결과의 단순성을 함께 지킬 수 있다.
- 감정: 안도 → 실천
- 장면: 행동가가 가벼운 설정으로 빠르게 작업을 완료한다. 옆에는 충전이 남은 토큰 배터리와 짧아진 타이머가 보인다. 세 인물이 완료된 깔끔한 결과를 함께 확인한다.
- 정확한 문구:
  - 행동가: “먼저 가볍게 시작!”
  - 안내자: “부족할 때 한 단계씩.”
  - 분석가: “더 빠르게, 토큰은 아끼고.”
- 화면 정보: 빠른 답변 + 토큰 절약 + 단순한 결과

## 게시물 핵심 결론

가장 높은 모델과 Effort가 항상 가장 좋은 결과를 만드는 것은 아니다. 작업의 목적·난이도·수정 범위에 맞춰 가볍게 시작하고, 실제로 막힐 때만 한 단계씩 높인다.
