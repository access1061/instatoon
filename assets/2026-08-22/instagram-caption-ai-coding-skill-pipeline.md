AI에게 “이 기능 만들어줘”라고 한 번만 말했는데, 코드는 길고 화면은 어딘가 어색하고 실행하면 오류가 난다면? 모델의 실력보다 작업 순서가 비어 있었을 가능성이 큼.

기획은 grill-me로 요구사항과 예외를 확정하고, taste-review로 화면의 타이포·여백·색을 점검. react-best-practices로 구조와 성능을 다듬은 뒤 simplify로 불필요한 래퍼와 추상화를 걷어냄. 마지막은 test-app으로 실제 실행 → 클릭 → 콘솔 → 스크린샷까지 확인.

다섯 스킬을 한꺼번에 도입할 필요는 없음. 기획이 자주 흔들리면 grill-me, 검증을 자주 놓치면 test-app처럼 가장 약한 구간부터 하나씩 연결하는 방식이 현실적임. 공개 벤치마크는 아직 충분하지 않으니 팀에 맞지 않는 절차는 덜어내는 것도 중요.
