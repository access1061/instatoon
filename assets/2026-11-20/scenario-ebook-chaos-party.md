# 코딩은 모르겠고, 파티는 모였습니다

## 작업 범위와 확인 상태

- 시나리오만 작성. 4:5 캐러셀 5장, 장마다 한 이미지 안에 상하 두 컷.
- 이미지 생성·QA·캡션 작성·발행·추가 에이전트 실행 없음.
- 셸과 Node 읽기 도구가 실행 환경 오류로 실패했다. AGENTS.md·워크플로·request.md·선택 스킬은 요청에 제공된 전문을 기준으로 적용했다. 캐릭터 프로필 및 ebook.html·supplement.html 원본은 직접 읽지 못했다. 아래 근거는 요청의 ‘확인한 원자료 핵심’에 한정한다. 제작 전 원본 대조 필요.
- refer/1116/chikawa.jpg, refer/1116/chikawa2.jpg 및 기존 판타지 작업물은 경로만 전달받았으며 실제 이미지 열람·특징 분석은 하지 않았다.

## 공통 연출

퇴근 후 PC 앞에 모인 이상한 제작 파티. 첫 장의 ‘못 해!’가 마지막 장의 ‘또 해?’로 돌아온다. 사건은 허구의 팬 각색이며 책에서 실제로 일어난 일이나 원작 대사가 아니다.

치이카와 7종은 작은 몸, 고유 얼굴·귀·색·실루엣을 유지한다. 프리렌·페른·슈타르크와 각자 독립된 캐릭터로 등장하며 외형을 합성하지 않는다. 기본 컷당 2~3인, 마지막 하단만 10인 단체. 지정 문구 외 장식용 문장은 넣지 않는다. 화면·파일 소품은 크게 단순화하고 실제 프로그램 UI처럼 꾸며낸 메뉴는 쓰지 않는다.

## 1장 — 코딩 공포에 파티 결성

**장 역할:** 도입 / 겁먹음 → 의외의 첫 성공.

**핵심 의미:** Windows PC의 Claude Code에 부탁해 폴더 속 실제 파일을 만들고 브라우저로 확인하는 실습. 직접 코드를 쓰지 않는다는 뜻이다.

### 상단 컷

**캐릭터 행동:** 슈타르크가 PC 앞에서 책을 펼치자 치이카와가 책 뒤에 숨는다. 프리렌은 전투 준비 대신 책의 부탁 문장을 가리킨다. 책 주변에 겁먹은 동작선만 두고 코드 폭포는 넣지 않는다.

**Text to render exactly:**
- 슈타르크: “코딩? 나 못 해!”
- 프리렌: “부탁 문장부터 붙여 넣어.”
- 치이카와: “히익…”

### 하단 컷

**캐릭터 행동:** 하치와레가 재료 폴더를 먼저 가리키고 프리렌이 Claude Code 대화창에 문장을 붙여 넣는다. 슈타르크는 브라우저에 뜬 카드 한 장을 보고 의자를 뒤로 밀 만큼 놀란다. 재료 확인 → 카드 한 장 확인의 순서가 시선으로 읽히게 한다.

**Text to render exactly:**
- 하치와레: “재료 파일부터 확인!”
- 슈타르크: “진짜 한 장 생겼어!”
- 화면 구분 표기: “Claude Code” / “브라우저”

**ebook 근거:** Windows PC·폴더 내 파일 생성과 수정, 프롬프트 복사·붙여넣기, 본문 1장의 재료 확인·카드 한 장·브라우저 확인. 웹 채팅만으로 끝내는 것으로 묘사하지 않는다.

## 2장 — 정보 짐더미 압수 사건

**장 역할:** 확장 / 욕심 → 독자의 질문으로 정리.

**핵심 의미:** 카드 한 장은 독자의 질문 하나. 기획표를 확인한 뒤 5장으로 확장하고 자료 밖 내용은 넣지 않는다.

### 상단 컷

**캐릭터 행동:** 모몽가가 작은 카드 틀에 거대한 종이 뭉치를 밀어 넣는다. 카드 틀은 휘어지고, 페른은 새 종이를 올리려는 손을 조용히 붙잡는다. 종이에는 읽을 수 있는 가짜 정보나 수치를 쓰지 않는다.

**Text to render exactly:**
- 모몽가: “내 얘기 전부 넣어!”
- 페른: “한 장엔 질문 하나.”

### 하단 컷

**캐릭터 행동:** 시사가 다섯 칸짜리 기획표를 펼친다. 랏코가 기획표와 재료를 대조한다. 모몽가는 몰래 덧붙이려던 빈 종이를 등 뒤로 숨긴다. 기획표 뒤에 카드 다섯 장이 순서대로 놓인다.

**Text to render exactly:**
- 시사: “기획표부터 확인해요!”
- 랏코: “자료에 없는 건 빼자.”
- 소품 표기: “기획표”

**ebook 근거:** 본문 2장의 질문 하나당 카드 한 장, 기획표 확인 후 5장 확장, 자료에 없는 내용 생성 금지.

## 3장 — ‘예쁘게’ 주문 실패

**장 역할:** 전환 / 막연한 기대 → 구체적인 수정 요청.

**핵심 의미:** 숫자·실제 증상·수정 위치를 말하면 요청이 구체적이 된다.

### 상단 컷

**캐릭터 행동:** 프리렌이 화면을 향해 주문하듯 손을 들지만 작은 제목은 그대로다. 쿠리만쥬는 컵을 내려놓고 화면 가까이 몸을 기울여 글자를 읽으려 한다. 마법 효과로 프로그램이 움직였다는 표현은 피하고 프리렌의 몸짓만 과장한다.

**Text to render exactly:**
- 프리렌: “예쁘게 해 줘.”
- 쿠리만쥬: “글씨가 안 보여…”

### 하단 컷

**캐릭터 행동:** 페른이 화면 상단 제목 위치를 짚으며 요청한다. 쿠리만쥬는 커진 제목을 멀리서 읽고, 프리렌은 자신의 손을 내려다본다. 화면에는 수정 전후 제목 크기 차이만 보여 준다.

**Text to render exactly:**
- 페른: “위쪽 제목이 작아요. 48px로 바꿔 주세요.”
- 프리렌: “주문이 구체적이네.”

**ebook 근거:** 본문 3장의 숫자·증상·수정 위치로 요청하기. ‘48px’는 이 장면에서 캐릭터가 고른 예시 요청값이며 책의 권장 수치나 인용문으로 제시하지 않는다.

## 4장 — 우사기 속도전과 저장 착각

**장 역할:** 위기 / 움직임 욕심 → 읽을 시간과 저장 절차 확보.

**핵심 의미:** 제한된 세 가지 움직임을 사용하고 4.8초씩 5장, 총 24초를 확보한다. 미리보기와 파일 저장은 다르다.

### 상단 컷

**캐릭터 행동:** 우사기가 카드 소품을 너무 빠르게 넘겨 슈타르크의 눈이 빙글 돈다. 랏코가 우사기의 손 앞에 정지 손짓을 한다. 과한 속도는 파티의 소동이며 실제 도구 동작이 아니다.

**Text to render exactly:**
- 우사기: “우라!”
- 슈타르크: “읽기도 전에 지나가!”
- 랏코: “장당 4.8초. 움직임은 세 가지만.”
- 하단 작은 수식: “4.8초 × 5장 = 24초”

### 하단 컷

**캐릭터 행동:** 미리보기 재생을 본 하치와레가 완성 포즈를 취한다. 시사가 빈 출력 폴더를 가리키자 하치와레의 앞발이 멈춘다. 우사기는 옆에서 저장 순서 카드 세 개를 차례대로 놓는다.

**Text to render exactly:**
- 하치와레: “다 됐다!”
- 시사: “미리보기예요. 파일도 확인해요!”
- 순서 소품: “png → check → video”

**ebook 근거:** 본문 4장의 제한된 세 가지 움직임·4.8초×5장=24초, 본문 5장의 png→check→video 및 미리보기와 저장 완료의 구분. 세 움직임의 구체적 종류는 제공 요약에 없으므로 임의 명명하지 않는다.

## 5장 — 끝난 줄 알았더니 다시 저장

**장 역할:** 해결·콜백 / 한 번 만든 결과 → 내 주제로 재사용.

**핵심 의미:** 수정 후 화면 확인과 재저장·파일 확인·발행 전 점검이 필요하다. 결과물과 전자책 본문·설치 별책을 소개한다.

### 상단 컷

**캐릭터 행동:** 모몽가가 수정된 화면만 보고 의기양양하게 나가려 한다. 페른이 출력 파일을 가리키며 붙잡고, 치이카와가 저장을 다시 하는 손 옆에서 고개를 끄덕인다. 화면 확인을 마친 뒤 파일을 다시 확인하는 흐름을 짧은 화살표로 표시한다.

**Text to render exactly:**
- 모몽가: “고쳤으니 끝!”
- 페른: “다시 저장하고 파일 확인.”
- 치이카와: “응!”
- 작은 절차 표기: “수정 → 화면 확인 → 재저장 → 파일 확인 → 발행 전 점검”

### 하단 컷

**캐릭터 행동:** 전원 10인 단체. 앞쪽 치이카와·하치와레가 PNG 카드 다섯 장을 펼치고, 우사기는 짧은 동작으로 옆을 뛰어간다. 모몽가는 자신의 차례를 가리키며 손을 들고, 쿠리만쥬는 컵을 든 채 지켜본다. 랏코는 결과 파일을 살피고 시사는 본문과 설치 별책 두 권을 받친다. 뒤쪽 프리렌은 다음 원고를 내밀고 페른은 확인표를 든다. 슈타르크가 첫 장과 같은 자세로 놀라지만 이번에는 웃는다. 10인을 같은 크기로 밀어 넣지 않고 앞·뒤 두 줄로 배치한다. 주요 대사는 두 개만 둔다.

**Text to render exactly:**
- 프리렌: “이번엔 우리 주제로.”
- 슈타르크: “또 해? 이제 할 만한데!”
- 결과물 표기: “PNG 5장 · 1080×1350”
- 결과물 표기: “음악 포함 MP4 · 1080×1920 · 24초”
- 소개 문구: “코딩 몰라도 말로 만든다: Claude로 움직이는 카드뉴스 만들기”
- 소개 보조 문구: “실습 본문 + 설치·로그인 별책”

**ebook 근거:** 본문 6장의 수정·화면 확인·재저장·파일 확인·발행 전 점검과 내 주제 재사용. 결과물 PNG 5장 및 음악 포함 세로 MP4 규격. 설치·로그인은 별책 제공. 소개 문구는 접근 방법·가격·배포 여부를 주장하지 않는다.

## 캡션 단계로 넘길 정보 메모 — 캡션 본문 아님

현재 지시에 따라 게시용 캡션 초안은 작성하지 않는다. 이미지가 완성된 뒤 100~500자 안에서 다음 누락 정보를 우선 보완한다.

- 직접 코드를 쓰지 않아도 프로그램 설치와 준비는 필요함.
- 1~4장은 Claude Code, 5장 내보내기는 Python·Playwright·Edge·FFmpeg 준비 필요.
- Claude 부탁 문장은 Claude 대화창, Python 저장 명령은 별도 PowerShell 창에 입력.
- 그림·폰트·음악·도구가 있는 start 폴더와 설치·로그인 별책을 확인.
- 예제 행사는 실습 자료이며 최신 행사 홍보가 아님. 그림·음악의 공개 사용 범위 확인.
- 무료 여부, 실습 파일 URL, 프로필 링크, 댓글 자동발송, 신청 방식, 가격을 추가하지 않음.
