사용자가 최종 지정한 03_plan.html을 인스타툰 4장으로 각색했다.

1. 01-be-specific.png — 막연한 요구 대신 문제 위치 관찰
2. 02-specify-layout.png — 실제 픽셀과 수정 범위 지정
3. 03-fix-the-symptom.png — 관찰 증상을 전달하고 필요한 배치만 수정
4. 04-review-and-record-v2.png — 전체 카드 재확인과 실제 적용값 기록

접미사 없는 04-review-and-record.png는 수정 전 시안이다. 게시에는 위 최종 v2를 사용한다.

2장의 수치는 원문의 예제 요청값이며 모든 카드뉴스에 적용하는 권장값이 아니다. 실제 코드를 실행한 화면이 아닌 학습 방법을 설명하는 팬 각색 그림이다. 외부 발행은 수행하지 않았다.

이전 02_install.html 기반 01-five-cards.png는 상위 폴더에 취소 시안으로 보존하며 이 결과에 포함하지 않는다. 원본 캐릭터 참고 2장과 1화 스타일 앵커를 실제 이미지 입력으로 사용했고, 2~4장은 독립 QA를 통과한 새 첫 장을 스타일 앵커로 사용했다. 의상과 한국어 대사는 이번 각색이다.
