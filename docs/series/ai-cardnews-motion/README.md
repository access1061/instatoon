## 최신 의도

유행한다는 AI 콘텐츠 제작을 배우려는 입문자가 비싼 유료 강의부터 결제해야 할지 고민하는 데서 출발한다. 작은 예제를 직접 바꿔 보고 필요한 학습을 판단하게 돕는 5회 연재다. 도구 소개와 설치 명령 나열보다 공감→작은 행동→확인 가능한 변화가 우선이다.

독자는 사용자가 지정한 20~30대다. 기본 판타지 파티 외에 치이카와 출연진을 활용하도록 요청했으며, 이번 시리즈에는 치이카와 캐릭터와 상황별 코스튬·액세서리·감정·액션을 적용한다. 팬층 연령 통계를 조사한 결과는 아니다.

## 바로 이어서 진행하기

1. `AGENTS.md`와 `docs/character-profiles/chiikawa.md`를 읽는다.
2. 이 폴더의 `ep01-manuscript.md`, `ep01-caption-draft.md`를 읽는다. 팀 원고는 `docs/jobs/2026-11-16-ai-motion-ep01/plan.md`이며 최초 3종 구성의 기록이다. 이후 승인된 우사기 수정은 `ep01-manuscript.md`가 최신 기준이다. 우사기는 3장에서 '우라!' 하며 글자 카드를 옮기고, 5장에서 '야하!' 하며 제목을 가리킨다. 긴 설명 대사는 배정하지 않는다.
3. 사용자가 '2회차 작성' 또는 원고를 이어 달라고 하면 **예제의 문구 하나를 바꾸는 실제 행동**을 중심으로 2회차 원고를 쓴다. 출연 제안은 치이카와·시사·하치와레다. 1회 마지막 '오늘은 제목 하나만!'에서 이어진다.
4. 1회차 이미지는 이미 제작됐다. `assets/2026-11-16/ai-motion-ep01/README.md`에 최종본 순서와 버전이 기록되어 있다. 수정 요청 시 해당 최종본을 대상으로 편집하고 새 버전으로 보존한다. 1장 v3이 PASS 스타일 앵커이며 우사기 의상은 3장 v3이 추가 기준이다.
5. 사용자가 '이어서'라고 하면 1회차가 이미지까지 완료된 상태임을 반영한다. 2회차의 실제 문구 수정 예제·도구 환경과 요청 문구를 정리한 뒤 원고와 제작을 이어 간다. 1회차를 처음부터 다시 생성하지 않는다.
