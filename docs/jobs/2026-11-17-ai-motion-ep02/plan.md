# AI 카드뉴스·모션그래픽 2화 — 카드 한 장에서 다섯 장으로

## 1장
- **장 역할:** 1화의 ‘오늘은 제목 하나만!’을 받아 이번 학습 목표로 전환.
- **핵심 의미:** 같은 cardnews-practice와 Claude Code 대화를 이어가며 카드 한 장을 같은 디자인의 다섯 장으로 확장한다.
- **캐릭터 행동:** 퇴근 후 책상에 앉은 치이카와가 카드 한 장을 바라본다. 하치와레가 다섯 장으로 이어지는 연습 예제 그림을 가리키고, 시사는 메모장을 펼친다. 실제 앱 캡처처럼 그리지 않는다.
- **정확한 문구:**
  - 치이카와: “지난번엔 제목 하나만!”
  - 하치와레: “이번엔 같은 디자인으로 다섯 장!”
  - 시사: “같은 폴더, 같은 대화에서 이어가자.”
  - 예제 표시: “연습 예제”
  - 폴더 표시: “cardnews-practice”

## 2장
- **장 역할:** 확장하기 전에 카드별 질문을 나누는 기획 장면.
- **핵심 의미:** 카드마다 독자가 궁금해할 질문 하나를 맡긴다. 행사 정보는 연습 자료이며 현행 공지가 아니다.
- **캐릭터 행동:** 시사가 다섯 칸의 기획표를 작성한다. 치이카와와 하치와레는 각각 한 칸씩 짚으며 읽는다. 작은 캐릭터와 넓은 여백을 유지한다.
- **정확한 문구:**
  - 시사: “한 장에 질문 하나씩!”
  - 기획표: “1 표지 · 무슨 내용?”
  - 기획표: “2 기간 · 언제까지?”
  - 기획표: “3 장소·시간 · 어디서, 몇 시?”
  - 기획표: “4 테마 · 어떤 주제?”
  - 기획표: “5 방문 전 확인 · 뭘 확인하지?”
  - 작은 주석: “행사 정보는 연습 자료”

## 3장
- **장 역할:** 파일 수정 전에 기획을 검토하는 판단 장면.
- **핵심 의미:** 먼저 기획표를 요청하고 자료에 없는 정보는 삭제한다. 아래 요청은 제공된 원자료 요약에 근거한 요청 예시이며 원문 직접 인용으로 표시하지 않는다.
- **캐릭터 행동:** 치이카와가 짧은 요청문을 내민다. 시사는 기획표를 대조하며 근거 없는 항목을 지우고, 하치와레는 수정 차례를 기다린다. 하나의 이미지 안에서 상단은 요청, 하단은 검토 장면으로 구성한다.
- **정확한 문구:**
  - 요청 예시: “아직 파일은 수정하지 말고, 카드별 기획표부터 보여줘. 자료에 없는 정보는 빼줘.”
  - 시사: “없는 정보는 삭제!”
  - 하치와레: “기획부터 확인하자.”

## 4장
- **장 역할:** 확인한 기획을 파일 역할에 맞춰 반영하는 실행 장면.
- **핵심 의미:** cards.js는 문구·그림, theme.css는 배치를 맡는다. 같은 디자인으로 확장하는 이번 목표에 집중한다.
- **캐릭터 행동:** 하치와레가 문구·그림 메모와 배치 메모를 구분해 놓는다. 시사는 기획표와 카드 순서를 대조하고, 치이카와는 같은 디자인의 다섯 연습 카드를 펼친다. 긴 코드나 가짜 실행 결과는 그리지 않는다.
- **정확한 문구:**
  - 하치와레: “내용과 배치를 나눠서!”
  - 메모: “cards.js · 문구·그림”
  - 메모: “theme.css · 배치”
  - 시사: “기획표 순서대로 다섯 장.”

## 5장
- **장 역할:** 카드별 확인과 오류 대응으로 마무리하고 다음 회차로 연결.
- **핵심 의미:** feed.html을 새로고침하고 1~5 버튼으로 각각 확인한다. 겹치면 선택한 카드만 표시하도록 수정 요청한다. 다음에는 가장 긴 3번 카드의 배치를 다듬는다.
- **캐릭터 행동:** 하나의 이미지 안 상단에서 치이카와가 연습 예제의 1~5 선택 영역을 차례로 짚고 시사가 검수 메모를 남긴다. 하단에서 하치와레가 긴 3번 카드를 펼쳐 다음 과제를 보여준다. 검증 완료나 실제 실행 성공을 암시하는 화면은 사용하지 않는다.
- **정확한 문구:**
  - 안내: “feed.html 새로고침 → 1~5 각각 확인”
  - 시사: “겹치면 선택한 카드만 보이게 수정 요청!”
  - 치이카와: “한 장씩 확인해야겠네.”
  - 하치와레: “다음엔 가장 긴 3번 카드 배치!”
  - 예제 표시: “연습 예제”

## 제작 공통 기준
- **장 역할:** 5장 모두 4:5, 최종 1080×1350. 치이카와·시사·하치와레의 퇴근 후 학습 이야기.
- **핵심 의미:** 최신 지시인 ‘같은 디자인의 다섯 장으로 확장’을 우선한다. 폐기된 제목 하나 변경·변경 전후 비교는 이번 서사에 넣지 않는다. 예제 제목을 표시해야 할 때는 ‘퇴근 후 10분’으로 통일하며 완성 시간 약속으로 표현하지 않는다.
- **캐릭터 행동:** refer/1116/chikawa.jpg와 chikawa2.jpg의 작은 몸, 고유 얼굴·귀·색을 유지한다. assets/2026-11-16/ai-motion-ep01/01-course-question-v3.png의 선·파스텔 채색·밀도를 기준으로 삼는다. 첫 2화 PASS 이미지는 후속 장의 앵커로 사용한다. 시사는 기획표 작성·정보 삭제·검수를 실제 행동으로 수행한다.
- **정확한 문구:** 각 장에 지정한 문구만 사용한다. 긴 코드·가격·설치법·가짜 명령·가짜 앱 버튼을 추가하지 않는다.
