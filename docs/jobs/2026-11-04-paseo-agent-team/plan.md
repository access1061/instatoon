# Paseo Agent Team — 4장 기획

## 1장
- **장 역할:** 도입 — 시안과 구현 결과의 차이에 당황한다.
- **핵심 의미:** 고양이 시안과 실제 게임 속 고양이의 몸 비율이 반복해서 어긋났고, 그 차이를 말로 일일이 설명하기 어려웠다.
- **캐릭터 행동:** 붉은 머리 행동가가 나란히 놓인 고양이 시안과 구현 화면을 보며 당황한다. 시안은 균형 잡힌 고양이, 구현 화면은 몸통과 다리 비율이 어긋난 고양이로 단순하게 새로 그린다. 안내자와 분석가는 두 그림을 살핀다. 파티 인물의 비율은 정상으로 유지한다.
- **정확한 문구 — Text to render exactly:**
  - 행동가: “시안이랑 왜 다르지?”
  - 행동가: “어디부터 고쳐야 해?”
  - 분석가: “차이를 설명하기도 어렵네.”

## 2장
- **장 역할:** 전환 — 총괄이 별도 Visual QA 역할을 추가한다.
- **핵심 의미:** 제작만 반복하는 흐름에 시안과 구현 화면을 비교하는 검수 역할을 더했다.
- **캐릭터 행동:** 안내자가 총괄을 상징하며 두 고양이 그림을 분석가에게 건넨다. 분석가는 비교할 준비를 하고, 행동가는 제작 작업 옆에서 고개를 든다. 세 인물은 역할을 설명하는 연출이며 원문 저자의 경험을 자신들의 실제 경험으로 말하지 않는다.
- **정확한 문구 — Text to render exactly:**
  - 안내자: “Paseo 팀에 검수 역할을 추가해.”
  - 분석가: “나는 시안과 결과를 비교할게.”

## 3장
- **장 역할:** 작동 원리 — 검수 결과를 제작자에게 전달한다.
- **핵심 의미:** QA가 화면을 영역별로 분석해 차이를 찾아 ART 에이전트에게 전달했다.
- **캐릭터 행동:** 분석가가 두 고양이 그림의 몸 부분과 배경 부분을 각각 테두리로 짚는다. 비교한 영역에서 나온 짧은 시각 메모를 행동가에게 전달한다. 행동가는 고양이 몸 비율과 배경을 수정하는 동작을 한다. 안내자는 전달 흐름을 따라본다. 화면 내부에 별도 설명 문구나 수치는 넣지 않는다.
- **정확한 문구 — Text to render exactly:**
  - 분석가: “영역별로 차이를 찾고…”
  - 분석가: “ART에게 수정할 점을 전달!”
  - 행동가: “이제 뭘 고칠지 알겠어!”

## 4장
- **장 역할:** 결론과 한계 — 개선된 결과와 검수의 가치를 함께 보여준다.
- **핵심 의미:** 몸 비율과 배경이 개선되고 애니메이션도 정상 동작했지만, 결과가 완벽해진 것은 아니다. 핵심은 차이를 찾아내는 별도 검수 역할이다.
- **캐릭터 행동:** 행동가가 몸 비율이 개선된 고양이와 다시 만든 배경을 확인한다. 고양이의 간단한 움직임은 동작선으로만 표현한다. 분석가는 시안과 결과를 계속 비교하고, 안내자는 두 역할 사이를 가리킨다. 시안과 결과를 완전히 동일하게 그리거나 완벽을 뜻하는 도장·점수·문구를 넣지 않는다.
- **정확한 문구 — Text to render exactly:**
  - 행동가: “비율도 움직임도 좋아졌네!”
  - 분석가: “아직 완벽하진 않아.”
  - 안내자: “만드는 역할과 검수하는 역할을 나누자.”
