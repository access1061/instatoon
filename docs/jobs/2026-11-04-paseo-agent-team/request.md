# Paseo Agent Team 인스타툰 제작

출처: https://gyuha.com/post/2026/11/2026-11-03-paseo-agent-team/
보조 출처: https://paseo.sh/plugins/gyuha/agent-team
사용자 요청: 위 글 관련 내용으로 인스타툰 제작. 이미지와 게시 원고까지 완성한다.

## 확인한 원문 내용 (각색용 요약)

저자는 직접 만든 Paseo Agent Team 플러그인으로 게임을 제작했다. 고양이 시안과 실제 게임 화면이 달랐고 Godot Skeleton으로 몸을 구성한 결과가 반복해서 어긋났다. 차이를 말로 일일이 설명하기 어려워 시안과 구현 화면을 비교하는 Visual QA 역할을 추가했다. 총괄에게 시안에 맞게 수정하도록 요청하자 QA가 화면을 영역별로 분석해 ART 에이전트에게 전달했다. 몸 비율이 개선되고 배경 에셋이 다시 제작되었으며 애니메이션도 정상 동작했다. 완벽한 결과는 아니었다. 핵심은 제작만 반복하는 대신 차이를 찾아내는 별도 검수 역할을 둔 점이다.

설치 명령은 paseo plugin add gyuha/agent-team이다. 이 플러그인은 역할별 provider/model을 선택하고 총괄이 일을 배분한다. 모든 역할이 같은 작업공간을 공유한다. 이 콘텐츠에서는 설치 명령과 세부 UI는 게시 캡션에서 보완하고 이미지에는 핵심 사건과 QA 구조를 담는다.

## 제작 조건

- 4장 캐러셀, 각 최종 이미지 1080×1350, 컬러 4:5. 원본 자르거나 늘이지 않고 흰 여백으로 보정한다.
- fantasy-party-insta-toon 고정 3인 파티: 은백발·청록 눈·뾰족 귀·붉은 물방울 귀걸이·흰금 옷 안내자, 붉은 머리/검은 앞머리·적흑 모험가 행동가, 긴 짙은 보라 머리·보라 눈·남색흰 옷 분석가.
- 밝은 흰 배경, 얇고 깔끔한 검은 선, 부드러운 셀 채색, 2~3등신, 넉넉한 말풍선 여백. 상하 2분할은 강제하지 않는다.
- 기획 흐름: 1 시안과 다른 고양이 결과에 당황 → 2 총괄이 Visual QA를 추가 → 3 QA가 영역별 차이를 찾아 제작자에게 전달 → 4 개선된 고양이와 검수의 가치, 완벽하지 않다는 한계.
- 실제 원문의 게임 스크린샷을 복제하지 않고 고양이 시안·결과를 간단한 상징 그림으로 새로 그린다. 캐릭터와 게임의 문제를 혼동하지 않게 파티 인물은 정상 비율을 유지한다.
- 원문을 한국어로 새로 각색하고 대사 2~3개, 장당 핵심 의미 하나만 담는다. 불필요한 제목/로고/이름/문구는 넣지 않는다. 효과나 속도 수치, 완전 자동/완벽 개선 주장을 만들지 않는다.
- 첫 장 PASS 후 실제 생성 이미지를 후속 장의 스타일·캐릭터 앵커로 입력한다.
- 게시 캡션 100~500자, 설명형 반존대, 그림의 대사 반복보다 설치와 역할 분리·한계를 보충, 해시태그 3~8개. 원문 저자의 경험을 우리의 경험으로 쓰지 않는다.
