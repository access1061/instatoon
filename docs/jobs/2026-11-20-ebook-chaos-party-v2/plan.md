# 무료 ebook 소개 인스타툰 페이지 계획

5장, 각 장은 하나의 4:5 이미지 안에 상하 두 컷. 최종 크기 1080×1350. handdrawn-illustrations3의 참고 이미지 우선 흐름을 적용한다. 사용자 지정 캐릭터의 고유 외형을 유지하고 서로 합성하지 않는다. 치이카와 7종과 프리렌·페른·슈타르크는 장면별로 분산 출연한다. 우사기는 짧은 외침만 한다.

참고: refer/1116/chikawa.jpg, refer/1116/chikawa2.jpg, assets/2026-08-13/01-free-stock-mcp-hook-instagram.png. 둥근 검은 선, 부드러운 채색, 파랑·크림색과 분홍 볼, 작은 팔다리, 판타지 인물의 2~3등신 비율, 흰 배경과 넓은 말풍선을 반영한다. 제작 시 실제 참고 이미지를 입력하며 첫 장 QA PASS 후 해당 이미지를 후속 장의 앵커로 추가한다.

## 1장 — 무료 전자책의 목적 소개

- **장 역할:** 만들고 싶은 결과와 무료 전자책의 학습 목적을 도입부터 연결한다.
- **핵심 의미:** 코딩이 낯선 초보자가 Claude Code에 말로 부탁하며 카드뉴스와 영상을 따라 만들어 본다.
- **캐릭터 행동:** 상단에서 치이카와가 카드뉴스·세로영상 예시를 가리키고 슈타르크가 겁먹는다. 하단에서 프리렌이 얇은 전자책을 펼치고 하치와레가 노트북과 책을 연결한다. 슈타르크는 기대하는 표정으로 바뀐다.
- **정확한 문구 — Text to render exactly:**
  - 제목: `AI로 카드뉴스와 영상 만들기`
  - 상단 치이카와: `나도 카드뉴스 만들고 싶어!`
  - 상단 슈타르크: `코딩을 몰라도 될까?`
  - 하단 프리렌: `Claude Code에 말로 부탁해 보자.`
  - 하단 설명박스:
    ```text
    카드뉴스 5장 + 24초 세로 영상
    따라 만들며 배우는 무료 전자책
    ```
- **어색함 수정 이유:** 만들 대상과 도구를 명시해 목적어 없는 반응을 없앤다. 설명박스의 `무료 전자책`을 눈에 띄게 강조한다.

## 2장 — 한 장에서 다섯 장으로

- **장 역할:** 정보를 한꺼번에 넣으려는 실수를 통해 시작 순서를 보여준다.
- **핵심 의미:** 재료를 확인하고 한 장부터 만든 뒤, 질문 하나씩 다섯 장으로 확장한다.
- **캐릭터 행동:** 상단에서 모몽가가 정보 종이를 한 카드에 욱여넣고 페른이 제지한다. 하단에서 시사가 내용을 다섯 칸으로 나누고 모몽가가 납득한다.
- **정확한 문구 — Text to render exactly:**
  - 제목: `처음엔 카드 한 장부터`
  - 상단 모몽가: `전부 한 장에 넣어 줘!`
  - 상단 페른: `한 장엔 질문 하나씩.`
  - 하단 시사: `내용을 나눠 다섯 장으로!`
  - 하단 설명: `재료 확인 → 한 장 만들기 → 다섯 장으로 확장`
- **어색함 수정 이유:** 욕심→제지→분할 행동으로 정보 과밀 문제와 해결을 연결한다.

## 3장 — 증상을 말하고 결과 확인하기

- **장 역할:** 처음 결과가 마음에 들지 않을 때의 구체적인 수정 방법을 보여준다.
- **핵심 의미:** 원하는 부분을 말하고 결과를 확인하며 여러 번 수정한다.
- **캐릭터 행동:** 상단에서 치이카와가 작은 제목을 읽으려 찡그리고 쿠리만쥬가 컵을 내려놓는다. 하단에서 페른이 제목만 짚고 치이카와가 수정 전후를 보며 웃는다. 화면은 실제 UI 캡처가 아닌 단순 삽화로 표현한다.
- **정확한 문구 — Text to render exactly:**
  - 제목: `안 되면, 다시 물어보기`
  - 상단 치이카와: `제목이 너무 작아…`
  - 하단 페른: `제목을 더 크게, 두 줄로 바꿔 줘.`
  - 하단 치이카와: `이제 잘 보여!`
  - 하단 설명: `원하는 부분을 말하고, 결과를 보며 수정해요.`
- **어색함 수정 이유:** 막연한 꾸미기 요청을 읽기 어려운 증상과 구체적인 변경 요청으로 바꿔 학습 흐름을 명확히 한다.

## 4장 — 읽을 시간 배분과 파일 저장

- **장 역할:** 움직임을 붙이고 결과를 파일로 저장하는 단계를 보여준다.
- **핵심 의미:** 책의 24초 영상 안에서 읽을 시간을 배분하고 PNG 이미지와 MP4 영상으로 저장한다.
- **캐릭터 행동:** 상단에서 우사기가 마우스로 폭주해 영상 속 제목과 카드가 빠르게 뒤섞이고 슈타르크가 당황한다. 하단에서 랏코가 타이머를 가리켜 읽을 시간을 안내하고, 시사가 카드 다섯 장과 영상 결과를 확인한다. 우사기는 만족한다. 가짜 UI 메뉴는 넣지 않는다.
- **정확한 문구 — Text to render exactly:**
  - 제목: `움직임을 붙이고, 파일로 저장`
  - 상단 우사기: `우라!`
  - 상단 슈타르크: `잠깐, 글을 못 읽겠어!`
  - 하단 랏코: `천천히, 읽을 시간을 주자.`
  - 하단 정보:
    ```text
    카드 5장 → 24초 영상
    PNG 이미지와 MP4 영상으로 저장
    ```
- **어색함 수정 이유:** 전체 영상 길이를 늘린다는 묘사 없이 24초 안의 읽을 시간 배분으로 표현한다.

## 5장 — 제작 과정 공유와 재시도 격려

- **장 역할:** AI와 함께 만든 전자책의 무료 배포를 알리고 편안한 재시도로 마무리한다.
- **핵심 의미:** 전자책도 AI와 함께 제작할 수 있으며, 처음 안 되어도 질문·확인·수정을 이어 간다.
- **캐릭터 행동:** 상단에서 프리렌과 시사가 완성 카드·영상·전자책을 책상에 펼치고 하치와레가 결과를 본다. 하단에서 페른·슈타르크·치이카와·하치와레가 작게 축하한다. 우사기는 책 옆 의자에서 다음 시도를 하는 시각 개그로 배치한다. 과밀하면 축하 인물 수를 줄이고 문구 의미는 유지한다.
- **정확한 문구 — Text to render exactly:**
  - 제목: `이런 전자책도 AI와 함께`
  - 상단 프리렌: `만든 과정을 전자책으로 나눠요.`
  - 하단 페른: `처음엔 안 돼도 괜찮아요.`
  - 하단 슈타르크: `물어보고, 고치고, 다시 해보자!`
  - 하단 책표지/소개:
    ```text
    코딩 몰라도 말로 만든다
    Claude로 움직이는 카드뉴스 만들기
    ```
  - 하단 배지: `무료 배포 · 설치·로그인 별책 포함`
- **어색함 수정 이유:** 결과와 제작 과정을 연결하고, 즉시 완성이나 성공 보장 대신 구체적인 재시도 행동으로 끝낸다.
