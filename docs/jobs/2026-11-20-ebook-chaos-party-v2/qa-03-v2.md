## 미확인 사항·도구 한계

- 셸 호출은 `helper_unknown_error: setup refresh had errors`로 실패했다. 로컬 문서의 디스크 내용은 직접 읽지 못했으며, 제공된 전문을 사용했다. 실제 이미지 열람은 성공했으므로 BLOCKED_TOOL에 해당하지 않는다.
- 실제 픽셀 크기의 별도 파일 메타데이터 검사는 실행하지 못했다. 정확히 1080×1350이라는 기계 검사는 요청문에 명시된 총괄의 저장 후 확인에 근거한다. 최종 파일을 직접 열어 보정 후 가독성과 전체 구성은 확인했다.
- raw 원본과의 픽셀 단위 비교는 수행하지 않았다. 원본 전체 보존 여부는 총괄의 비율 유지·흰 여백 보정 확인을 전제로 한다.
- 장간 비교는 제공된 1장 앵커 범위다. 2·4·5장 전체의 일관성 판정이나 캡션 검수는 이번 3장 QA 범위에 포함하지 않는다.

이미지·캡션 수정, 다른 작업자 파일 변경, 에이전트 시작, 게시를 수행하지 않았다.
