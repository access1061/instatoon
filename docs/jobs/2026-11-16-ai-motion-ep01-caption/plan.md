# 승인된 1회차 계획 요약

새 기획이 아니라 원본 작업 plan.md와 실제 완성 이미지의 캡션 전달용 요약이다. 이미지는 모두 생성·최종 보정·독립 시각 QA가 끝났다.

1. 치이카와(크림 카디건)가 강의 결제를 고민, 하치와레(민트 후드)가 함께 봄.
2. 하치와레가 예제 한 장을 제안하고 노트북을 보여줌.
3. 그림·글자·도형을 구분. 우사기(연노랑 후드·헤드폰)가 '우라!' 하며 글자 카드를 옮김. 하치와레가 설명.
4. 쿠리만쥬(브라운 니트)가 메모지를 건네며 시도 후 막힌 곳부터 배우자고 제안.
5. 우사기 '야하!', 치이카와가 오늘은 제목 하나만 바꾸기로 결심. 2회 '예제에서 문구 하나 바꾸기'로 연결.

실제 문구 수정·영상 제작이 이 회차에서 완료됐다는 의미는 아니다. 내용은 그림에서 설정한 다음 행동이다. 코스튬과 관계는 팬 각색이다.
