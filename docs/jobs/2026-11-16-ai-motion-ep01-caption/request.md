# 완성 이미지 5장 캡션

원본 작업: docs/jobs/2026-11-16-ai-motion-ep01-images. 모든 이미지와 독립 QA 원본은 그 작업에 보존된다. 누적 QA 전문으로 Windows 명령 길이 제한이 발생해 캡션 전달만 이 축약 작업으로 분리한다.

첨부 1~5는 순서대로 QA를 통과한 완성 이미지다. 실제 이미지를 보고 공백 포함 100~500자 한국어 게시 캡션을 작성한다. caption.md에는 게시 본문과 관련 해시태그 3~8개만 저장한다. 제목·검수 설명은 넣지 않는다. 파일 도구 오류 시 apply_patch 사용. 원문 직접 읽기 여부를 과장하지 않는다. 이미지 열람 실패면 그 사실을 알린다.

주제: AI 카드뉴스·모션그래픽을 배우기 위해 비싼 유료 강의부터 결제해야 할까? 작은 예제부터 시도하고 막힌 부분에 맞춰 학습을 판단하자는 5회 연재 중 1회. 독자는 사용자가 지정한 20~30대 입문자다. 실제 팬층 통계나 유행 규모를 조사한 것은 아니다.

그림 대사를 반복하지 말고 예제 문구 수정→구체적인 AI 요청→움직임 하나 추가의 학습 순서, 강의료와 도구 이용료가 별개임, 실행 환경 준비가 필요함을 보완한다. 강의 불필요·무료·즉시 완성을 단정하지 않는다. 가격·최신 버전·근거 없는 성과는 추가하지 않는다. 실제 예제 URL이 없으므로 링크·DM 배포를 약속하지 않는다. 다음 편 문구 수정 안내는 가능하다.

최종 파일 5장 모두 총괄이 1080×1350 및 무크롭·비율 유지 보정의 픽셀 일치를 검사했다. 각 이미지의 SHA256은 원본 작업 artifact-verification.json에 있다.
