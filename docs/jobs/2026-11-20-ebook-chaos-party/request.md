사용자 요청: E:\Pi_workspace\naver_blog\final\ebook 공개용 ebook 내용을 요약하여 현재 사용한 치이카와 캐릭터와 프리렌 일행을 모두 섞은 캐릭터 환장 파티 시나리오 작성.

이번 산출물은 시나리오만. 이미지 생성·이미지 QA·발행은 실행하지 않는다. 4:5 캐러셀 5장, 장마다 상하 두 컷을 기본으로 상세 시나리오 작성. 장 역할 / 핵심 의미 / 캐릭터 행동 / 정확한 문구를 기록한다. 재미있는 사건이 먼저이며 설명 대사로 가득 채우지 않는다.

선택 스킬 handdrawn-illustrations3. 사용자 명시 캐릭터 우선으로 치이카와 7종(치이카와, 하치와레, 우사기, 모몽가, 쿠리만쥬, 랏코, 시사)과 프리렌·페른·슈타르크가 시리즈 전체에서 역할을 맡는다. 캐릭터를 합성하거나 사람 체형으로 바꾸지 않는다. 통상 컷당 2~3인, 마지막 단체는 전원을 넣되 주요 대사는 2개 이내. 원작 대사가 아닌 팬 각색. 우사기는 짧은 외침과 행동, 치이카와는 짧은 반응. 참고 경로는 refer/1116/chikawa.jpg, refer/1116/chikawa2.jpg 및 기존 판타지 파티 작업물. 이번에는 이미지 참고를 실제로 보았다고 주장하지 말 것. 프로필 docs/character-profiles/chiikawa.md 확인.

원자료: E:\Pi_workspace\naver_blog\final\ebook\ebook.html (본문), supplement.html (별책). 반드시 UTF-8로 읽는다. ebook 제목: 코딩 몰라도 말로 만든다: Claude로 움직이는 카드뉴스 만들기.

확인한 원자료 핵심:
- Windows PC의 Claude Code로 폴더 안에 실제 파일을 만들고 수정하는 왕초보 실습서. 웹 채팅과 구분.
- 독자는 책의 프롬프트를 복사·붙여넣고 실제 결과를 눈으로 확인. 사용자가 직접 코드를 작성하지 않는다는 의미이며 프로그램·설치가 필요 없다는 뜻은 아님.
- 결과물: 1080×1350 PNG 카드 5장, 음악을 포함한 1080×1920 24초 세로 MP4.
- 1장: 재료 파일부터 확인시키고 카드 한 장, 브라우저에서 확인.
- 2장: 카드 한 장은 독자의 질문 하나. 기획표부터 확인한 뒤 5장 확장. 자료에 없는 내용은 지어내지 않음.
- 3장: 예쁘게 해줘 대신 숫자와 실제 증상, 수정 위치로 요청.
- 4장: 제한된 세 가지 움직임. 4.8초×5장=24초. 읽을 시간을 확보.
- 5장: png → check → video 순서로 내보내기. PNG는 이미지, MP4는 영상. 미리보기만으로 저장 완료가 아님.
- 6장: 원고 수정 → 화면 확인 → 다시 저장 → 파일 확인 → 발행 전 점검. 내 주제로 재사용.
- Claude Code 부탁 문장은 Claude 대화창, python 저장 명령은 별도의 PowerShell 창.
- 1~4장은 Claude Code, 5장 내보내기에는 Python·Playwright·Edge·FFmpeg 준비.
- 설치와 로그인은 별책부록으로 따로 제공. 시작용 그림·폰트·음악·도구가 든 start 폴더 필요.
- 예제 행사는 실습 자료로 최신 행사 홍보가 아님. 그림·음악 공개 사용 범위 확인 필요.
- 무료 배포 여부·실습 파일 실제 배포 URL·프로필 링크·댓글 자동발송·신청 방식·가격은 확인 안 됨. 지어내지 말 것. 마지막 CTA는 전자책 제목과 본문·설치 별책 구성을 소개하는 문구만.
