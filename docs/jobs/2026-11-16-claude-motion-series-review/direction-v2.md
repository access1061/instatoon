# 시리즈 방향 수정: 강의 결제 전에 작은 결과물부터

## 후속 캐릭터·독자 지시 반영

현재 시리즈는 치이카와 출연진을 활용하는 방향으로 갱신한다. 삼총사만 반복하지 않고 치이카와·하치와레·우사기·모몽가·쿠리만쥬·랏코·시사 등 참고에서 확인한 7종을 장면에 맞춰 순환 활용한다. 20~30대 독자를 기준으로 퇴근 후 학습, 결제 고민, 콘텐츠 제작 상황에 맞는 코스튬·액세서리·감정·액션을 적용한다. 구체적 출연·연출 기준은 `docs/character-profiles/chiikawa.md`를 따른다. 기존 판타지 파티는 다른 작업에서 선택할 수 있도록 유지한다.

## 사용자가 밝힌 출발점

“AI로 모션그래픽 그리고 카드뉴스 생성하는 게 유행이라던데 비싸게 유료로 강의를 들을 필요가 있을까? 쉽게 배울 수 있는 방법은?”

이는 사용자가 제시한 독자의 관심과 질문이다. 실제 유행의 규모나 모든 유료 강의의 효용을 검증한 사실로 서술하지 않는다.

## 중심 메시지

처음부터 비싼 강의를 결제해야 하는 것은 아니다. 작은 카드뉴스 한 장을 만들어 보고, 같은 화면의 글자나 도형에 움직임을 붙이는 순서로 입문할 수 있다. AI에게 결과를 요청하고, 화면을 확인하고, 한 부분씩 수정하는 과정을 배운다. 강의는 직접 시도한 뒤 자신이 막힌 부분과 필요한 피드백을 기준으로 판단한다.

강의를 무가치하다고 단정하거나 누구나 무료로 즉시 완성할 수 있다고 약속하지 않는다. 강의료와 도구 구독료는 별개이며, 예제 실행과 AI에게 새 제작을 요청하는 경로도 구분한다. 현재 요금·이용 조건은 별도 확인 전 숫자로 소개하지 않는다.

## 독자와 이야기

독자는 코드를 배우려는 개발자가 아니라 AI 콘텐츠 제작에 관심이 생겼지만 비용과 난도가 부담스러운 입문자다.

행동가는 강의 광고를 보고 “나도 만들고 싶은데, 강의부터 들어야 하나?”라고 고민한다. 안내자는 작게 직접 만드는 순서를 제안한다. 분석가는 결과를 보며 수정 범위와 비용·도구의 한계를 짚는다. 완성 예제는 독자에게 가능성을 보여주고 따라 해볼 발판으로 사용한다.

가제: **AI 카드뉴스·모션그래픽, 강의부터 결제해야 할까?**

첫 제안의 6회×4장에 얽매이지 않고, 입문 질문에 집중한 5회×4장(총 20장)을 새 제안으로 둔다. 사용자 확정 장수는 아니다.

| 회차 | 독자 질문 | 4장의 흐름 | 가져갈 행동 |
| --- | --- | --- | --- |
| 1. 강의부터 결제해야 할까? | 나도 만들고 싶은데 비싼 강의가 필수일까? | 관심과 비용 고민 → 작은 완성본 제시 → 그림·글자·움직임의 구조 → 한 장부터 시도 | 배우고 싶은 결과 하나를 고른다. |
| 2. 쉽게 시작하려면 무엇부터? | 처음부터 새로 만들어야 하나? | 빈 화면 앞 막막함 → 예제 열기 → 문구 하나 바꾸기 → 바뀐 화면 확인 | 기존 예제에서 한 부분을 수정한다. |
| 3. AI에게 어떻게 부탁하지? | '예쁘게 만들어줘'로 충분할까? | 막연한 요청 → 필요한 자료 선택 → 내용·규격·분위기 지정 → 한 번에 한 부분 수정 | 짧고 구체적인 제작 요청을 쓴다. |
| 4. 카드뉴스를 움직이게 하려면? | 그림도 전부 다시 그려야 하나? | 정지 카드 제시 → 글자·도형을 별도 요소로 이해 → 순서대로 등장 → 읽을 시간 확인 | 제목 등장 같은 움직임 하나를 붙인다. |
| 5. 직접 해본 다음, 무엇을 배울까? | 계속 혼자 할까, 강의를 들을까? | 완성본 재생 → 막힌 단계 기록 → 필요한 학습·피드백 구분 → 다음 작업 선택 | 결제 여부를 자신의 막힘과 강의 내용으로 판단한다. |

## 첫 회차 대사 초안

| 장 | 캐릭터 행동 | 정확한 문구 초안 |
| --- | --- | --- |
| 1 | 행동가가 AI 콘텐츠 강의 화면과 자신의 빈 작업 화면을 번갈아 본다. | “AI로 이런 것도 만든대!” / “나도 강의부터 들어야 하나?” |
| 2 | 안내자가 카드 한 장과 같은 화면의 모션 버전을 보여준다. | “먼저 한 장 만들어 보자.” / “움직임은 그다음에 붙이고.” |
| 3 | 분석가가 화면을 그림·글자·도형으로 나누어 보여준다. | “화면을 나눠 보면 쉬워져.” / 정보 라벨: “그림 / 글자 / 도형” |
| 4 | 행동가가 예제에서 문구 하나를 바꾸며 시작한다. | “첫 목표는 문구 바꾸기!” / 안내자: “막히는 곳부터 배우면 돼.” |

가짜 가격·광고 문구·완성 시간은 넣지 않는다. '유행'은 첫 질문의 관심 표현으로 다루며 실제 시장 추세를 단정하지 않는다.

## 기존 원고 활용 방식

- final의 완성 결과와 파일 구조는 가능성을 보여주는 자료 및 예제로 활용한다.
- 설치·로그인·명령 전체는 따라 하기용 보충 원고로 분리한다. 첫 회차부터 도구 이름을 나열하지 않는다.
- 자료 선별, 구체적 프롬프트, 글자 레이어, 의미 있는 모션, 검수는 회차별 해결 장면으로 활용한다.
- 실제 렌더 경로와 HyperFrames 미완료 사실은 유지하되 첫 관심을 끄는 장면의 중심 주제로 삼지 않는다.
- 도구 비용·인증·환경 준비 등 실제 진입 장벽을 숨기지 않는다. '쉽다'는 작은 단계로 나눠 배운다는 뜻으로 사용한다.
- 최신 도구 추천·비용 비교·강의 비교를 제시할 때에는 해당 공식 자료와 실제 강의 내용을 확인한다. 이번 수정은 사용자 의도에 맞춘 편집 방향 설정이다.

## 상태

이 문서가 이전 result.md와 plan.md의 시리즈 중심 방향을 대체한다. 원고의 사실 검토와 한계 기록은 유지한다. 이미지 생성·게시 캡션·발행은 아직 진행하지 않는다.
