# 인스타툰 원고 — "터미널 코딩 에이전트 삼국지"
### Claude Code vs OpenCode vs MiMo Code (2026년 최신 기준)
> 형식: A4 1장 / 진행 캐릭터: 김개미 / 톤: 쉽고 담백하게, 팩트는 정확히

---

## [썸네일 / 컷 0]
- **그림**: 김개미가 검은 터미널 화면 3개 앞에 팔짱 끼고 서 있음. 화면마다 로고 느낌(🟣 Claude / ⚫ OpenCode / 🟠 MiMo).
- **큰 제목**: "AI가 대신 코딩하는 시대, 터미널 3대장 비교"
- **작은 글씨**: "이제 셋 다 '자동완성'이 아니라 '에이전트'입니다"

---

## [컷 1] 도입 — 뭐가 달라졌나
- **그림**: 김개미가 놀란 표정. 말풍선.
- **김개미**: "예전엔 코드 추천만 해줬잖아? 근데 얘넨 이제 파일을 직접 읽고·쓰고, 터미널 명령까지 스스로 실행해."
- **자막**: 셋 다 **터미널 네이티브 자율 코딩 에이전트**. 사람 대신 '작업'을 함.

---

## [컷 2] 🟣 Claude Code (앤스로픽)
- **그림**: 말끔한 정장 입은 캐릭터. "공식 인증" 배지.
- **김개미**: "앤스로픽이 직접 만든 '정품'. 설치 쉽고 IDE 연동이 제일 매끄러워."
- **강점**: 위험 명령 실행 전 사용자에게 확인 요청 등 **안전장치·완성도 최고**. 스킬/훅·백그라운드 에이전트·체크포인트.
- **단점**: **비공개(closed) + Claude 모델 전용 + 구독형**(Pro 기준 월 $20~). 선택지가 좁음.
- **자막**: 👉 복잡한 세팅 없이 **바로 실무 투입**하고 싶다면.

---

## [컷 3] ⚫ OpenCode (오픈소스)
- **그림**: 자유분방한 캐릭터가 모델 카드들을 저글링(Claude·GPT·Gemini·DeepSeek·로컬).
- **김개미**: "이 친구의 무기는 '자유'. 특정 회사에 안 묶여."
- **강점**: **MIT 오픈소스**, **75개+ 모델 프로바이더** 자유 스위칭(무료 로컬 Ollama까지). 무료 모델 번들 제공. **세션은 SQLite에 영구 저장 → SSH 끊겨도 이어서 작업**. Plan/Build 모드.
- **참고**: 깃허브 ⭐17만+·월 사용자 750만+ 급성장(SST 제작).
- **단점**: API 키·환경을 직접 관리 → 초기 셋업이 살짝 번거로움.
- **자막**: 👉 **벤더 종속 싫고, 비용·모델을 내 맘대로** 통제하고 싶다면.

---

## [컷 4] 🟠 MiMo Code (샤오미)
- **그림**: 신상 느낌 캐릭터, 머리에 "2026.6 출시" 리본. 뒤에 큰 뇌(메모리) 아이콘.
- **김개미**: "샤오미가 OpenCode를 '포크'해서 메모리를 확 키운 최신 툴이야."
- **강점**: **MiMo-V2.5 기본 탑재(100만 토큰·한시적 무료·가입 불필요)**. **SQLite FTS5 영구 메모리**로 세션이 끊겨도 프로젝트 맥락을 안 잊음. **Compose 모드**로 기획→코딩→테스트를 한 번에. `/dream`·`/distill` 자기개선 기능.
- **팩트체크**: MiMo-V2.5 모델 성능은 샤오미 공식 표현상 **"Claude Sonnet 4.6급"**(최상위 모델을 이긴다는 뜻은 아님).
- **단점**: 이제 막 나와서 커뮤니티·플러그인 생태계가 아직 미성숙.
- **자막**: 👉 **초장기·다단계 대형 프로젝트**, 맥락 유지가 중요하다면.

---

## [컷 5] ⚠️ 벤치마크, 오해 금지 (중요!)
- **그림**: 김개미가 "잠깐!" 하며 손 드는 컷. 옆에 성적표.
- **김개미**: "'MiMo가 Claude Code보다 낫다'는 말, 조건을 꼭 봐야 해."
- **핵심**: 샤오미 **자체 발표** + **같은 MiMo 모델을 양쪽에 넣고 '하네스(에이전트 구조)'만 비교**한 결과.
  - SWE-bench Pro: MiMo Code **62%** vs Claude Code 57%
  - Terminal Bench 2: MiMo Code **73%** vs Claude Code 68%
- **반대 팩트**: 같은 Terminal Bench 2에서 **OpenAI Codex CLI(GPT-5.5)는 82%대**로 더 높음.
- **자막**: 즉, "무조건 1등"이 아니라 **"긴 워크플로우에서의 하네스 강점"**으로 읽는 게 정확.

---

## [컷 6] 한 줄 정리 (표)
- **그림**: 김개미가 화이트보드에 매직으로 정리.

| | 🟣 Claude Code | ⚫ OpenCode | 🟠 MiMo Code |
|---|---|---|---|
| 성격 | 완성도 높은 공식 에이전트 | 자유도 극대화 오픈소스 | 긴 작업 특화 OpenCode 포크 |
| 라이선스 | 비공개 | MIT | MIT |
| 모델 | Claude 전용(최적화) | 75개+ 자유 선택 | MiMo-V2.5 + 타사 연동 |
| 비용 | 구독형 | 무료(API만 지불) | 한시적 무료 |
| 킬러 포인트 | 안정성·IDE·안전장치 | 벤더 프리·모델 자유 | 영구 메모리·Compose |

---

## [컷 7] 마무리 — 김개미의 추천
- **그림**: 김개미가 엄지 척, 뒤에 3개 화면이 나란히.
- **김개미**: "정답은 없어. **'뭐가 제일 세냐'가 아니라 '내 작업에 뭐가 맞냐'**가 기준이야."
  - 안정성·즉시 실무 → **Claude Code**
  - 자유·비용 최적화 → **OpenCode**
  - 초장기·다단계 → **MiMo Code**
- **CTA**: "당신의 코딩 스타일은 셋 중 뭐? 댓글로 알려줘요 👇"
