# 치이카와 출연진과 성인 독자용 연출 지침

## 적용과 우선순위

사용자가 치이카와 콘텐츠를 지정했을 때 적용한다. 프리렌 계열 판타지 파티는 유지되는 별도 선택지다. 치이카와 지정 없이 모든 작업을 치이카와로 바꾸지는 않는다. 사용자 지정 → 실제 참고 이미지 → 이 지침 순으로 따른다.

현재 사용자가 원하는 것은 삼총사의 사용 빈도만 높이는 것이 아니라, 활용 가능한 캐릭터 수를 늘리고 다양한 코스튬·액세서리·감정·액션을 적용하는 것이다.

사용자가 지정한 독자는 20~30대다. 직장 생활, 퇴근 후 자기계발, 콘텐츠 제작, 취미, 강의·구독 결제 고민처럼 공감할 상황을 사용한다. 실제 팬층 연령 분포를 조사한 결과로 표현하지 않는다.

## 실제 확인한 참고 이미지

- `refer/1116/chikawa.jpg`: 흰 배경, 둥근 검은 손그림 선, 작은 몸과 큰 얼굴, 분홍 볼, 단순한 눈·입, 흰색·크림색·파랑 포인트. 아래쪽 단체에 다양한 캐릭터가 있다.
- `refer/1116/chikawa2.jpg`: 같은 캐릭터의 단체 구성, 복숭아·크림색 빛과 꽃 배경, 부드러운 채색. 우사기의 긴 귀와 배 무늬, 하치와레의 파랑, 모몽가의 큰 꼬리 등을 비교할 수 있다.

각 생성에 해당 캐릭터가 실제로 보이는 참고 이미지를 이미지 입력으로 전달한다. 파일명만 적고 참조했다고 처리하지 않는다. 두 참고에서 하치와레의 파랑 모양 등 표현이 다르면 첫 안정 생성본에서 선택한 형태를 이후 장에 유지한다. 첫 QA 통과 이미지를 시리즈 앵커로 사용한다.

## 출연진: 우선 7종

아래 이름은 작업상 식별명이다. 아래 역할과 코스튬은 이 정보툰의 각색이며 공식 설정·공식 의상이라는 주장이 아니다. 원작의 성격·관계를 확인 없이 해설하지 않는다.

| 캐릭터 | 참고에서 유지할 외형 | 이번 정보툰에서 활용할 행동 |
| --- | --- | --- |
| 치이카와 | 흰 둥근 몸, 작고 둥근 귀, 분홍 볼, 짧은 팔다리 | 시작을 망설임, 작은 성공, 긴장 후 안도 |
| 하치와레 | 흰 몸과 파란 머리·귀 포인트, 고양이형 얼굴 | 같이 화면 보기, 단계 제안, 친구에게 설명 |
| 우사기 | 크림색 몸, 긴 귀와 분홍 안쪽, 둥근 배 무늬 | 먼저 버튼 누르기, 실험, 예상 밖 결과에 크게 반응 |
| 모몽가 | 흰 몸, 둥근 귀, 이마의 파랑 포인트와 큰 푸른 꼬리 | 결과 자랑, 전후 비교, 주목받고 싶은 반응 |
| 쿠리만쥬 | 둥근 갈색 머리 윗부분, 베이지색 몸, 작은 귀 | 쉬면서 비교, 결제 전 한 번 멈추기, 만족스러운 휴식 |
| 랏코 | 연한 크림색, 이마의 별 모양 포인트, 참고의 흰 목둘레와 검은 매듭 | 시범 보이기, 체크리스트 확인, 막힌 지점 짚기 |
| 시사 | 연한 노랑 몸, 얼굴 양옆의 붉은 장식·갈기 형태 | 메모하며 배우기, 꼼꼼한 준비, 끝까지 완성하기 |

새 참고에 다른 캐릭터가 추가되면 실제로 열고 외형을 확인한 뒤 출연진을 확장한다. 위 7종을 영구 상한으로 삼지 않는다. 이름이나 외형이 불분명하면 임의 캐릭터를 만들지 않는다.

## 캐릭터 수와 화면 밀도

- 시리즈 전체에서 삼총사 외 캐릭터도 실제 역할을 맡긴다. 뒤 배경의 장식으로만 추가하지 않는다.
- 보통 한 장에 주연 1~3명. 역할이 다른 조연을 회차 사이에 순환 배치한다. 역할을 모든 회차에 고정하지 않아도 된다.
- 표지·축하·마지막 단체 장면에는 4~7명을 활용할 수 있다. 한글과 행동이 작아지면 인원을 줄인다.
- 출연 인원을 채우기 위해 동일 캐릭터를 복제하지 않는다. 같은 장의 여러 컷에 재등장한 경우는 컷 경계로 명확히 구분한다.

## 코스튬과 액세서리

| 독자 상황 | 코스튬 선택 | 액세서리와 행동 |
| --- | --- | --- |
| 출근·업무 | 작은 셔츠·카디건·재킷·단정한 조끼 | 목걸이형 사원증, 작은 노트북, 텀블러. 급히 화면을 확인하거나 메모를 건넴 |
| 퇴근 후 학습 | 후드·맨투맨·편한 홈웨어 | 둥근 안경, 헤드폰, 태블릿. 졸다가 집중하거나 한 단계를 끝내고 기지개 |
| 카페 작업 | 니트·가벼운 셔츠·앞치마 | 토트백, 컵, 펜. 화면을 같이 보거나 수정 전후 카드를 펼침 |
| 콘텐츠 제작 | 작업 조끼·베레모·소매를 걷은 셔츠 | 펜 태블릿, 색상 카드, 카메라, 작은 스토리보드. 글자를 옮기고 효과를 시험 |
| 결제·구독 고민 | 평상복·외출 카디건 | 스마트폰, 지갑, 무문자 영수증. 결제 직전 멈춤, 옵션 비교, 필요 항목에 체크 |
| 완성·휴식 | 잠옷·담요·편한 니트 | 쿠션, 간식, 머그. 어깨 힘을 풀거나 완성 화면을 친구에게 보여줌 |

장면마다 코스튬 1벌과 핵심 액세서리 1~2개를 우선한다. 소품이 많다고 성인 독자에게 맞는 것은 아니다. 보이는 행동과 상황이 먼저다. 캐릭터를 꾸미는 장면이 목적이면 액세서리를 더할 수 있다.

귀를 모자로 완전히 가리거나 랏코의 이마 표식, 하치와레의 파랑, 모몽가의 꼬리를 지워 식별이 어려워지게 하지 않는다. 우사기의 긴 귀가 화면 밖으로 잘리지 않게 한다. 새 의상도 작은 몸의 비율에 맞춘다. 장면이 이어지는 동안 코스튬·안경·소품의 색과 위치를 유지하고, 장소나 시간 변화가 있을 때 의상을 바꾼다.

## 감정은 표정·자세·결과로 보여주기

| 감정 | 표정과 액션 | 짧은 대사 예시 |
| --- | --- | --- |
| 비용 부담 | 눈썹을 모으고 결제 버튼 앞에서 손을 멈춤 | “강의부터 들어야 하나?” |
| 시작의 막막함 | 빈 화면 앞에 몸을 작게 움츠리고 친구를 바라봄 | “어디서 시작하지?” |
| 호기심 | 몸을 앞으로 기울이고 귀를 세우며 화면을 가리킴 | “이것만 바꿔볼까?” |
| 집중 | 눈을 화면에 고정하고 짧은 팔로 펜을 잡음 | “제목부터 하나씩.” |
| 실패·당황 | 잘못된 결과를 보고 굳거나 고개를 갸웃함 | “왜 전부 바뀌었지?” |
| 작은 성공 | 화면을 돌려 보여주고 볼이 밝아지며 손을 듦 | “어, 바뀌었다!” |
| 안도 | 힘을 빼고 앉거나 친구와 손을 맞댐 | “한 단계는 했네.” |
| 확신·판단 | 수정 전후를 나란히 놓고 한쪽을 선택 | “이쪽이 더 잘 읽혀.” |

긴 설명을 표정 없는 캐릭터에게 읽히지 않는다. 한 컷에 주감정 하나를 두고, 한 장의 감정 변화가 필요하면 컷을 나누거나 명확한 전후 구도를 사용한다. 매 장 눈물·비명·과장 반응만 반복하지 않는다.

## 대사와 정보의 분리

- 우사기는 긴 설명·일반적인 한국어 문장·설명형 속마음 대신 '우라!', '야하!' 같은 짧은 외침과 귀·시선·몸짓·직접 행동으로 의사를 보여준다. '말을 전혀 못한다'는 절대적 설정으로 단정하지 않는다. 기술 설명이 필요하면 하치와레나 정보 카드에 배정하며 우사기의 외침을 장문으로 번역하지 않는다. 참고 확인: https://www.anime-chiikawa.jp/ (공식 캐릭터 소개, 2026-11-16 확인).

- 치이카와·우사기는 짧은 반응과 몸짓을 적극 활용한다. 기술 설명은 하치와레·다른 등장인물의 짧은 말이나 별도 정보 카드로 보완한다.
- 팬 각색으로 필요한 한국어 대사를 사용할 수 있으나, 원작 대사라고 소개하지 않는다.
- 장당 말풍선 2~4개 이내를 우선하며 하나에는 한 가지 뜻만 둔다. 정확한 문구는 `Text to render exactly:` 아래에 적는다.
- 실제 명령·가격·일정·앱 화면은 원자료와 대조한다. 원자료가 없는 가짜 화면을 실제 캡처처럼 그리지 않는다.

## 현재 AI 카드뉴스·모션그래픽 시리즈 적용안

사용자가 밝힌 출발 질문: “유행한다는 AI 모션그래픽·카드뉴스를 배우려고 비싼 유료 강의를 들어야 할까? 쉽게 배우는 방법은?”

기획 대상은 20~30대 입문자다. 퇴근 후 배우기, 강의 결제 망설임, 처음 수정한 화면의 기쁨을 중심으로 연출한다. 실제 팬층 통계나 현재 유행 규모를 입증했다고 주장하지 않는다.

| 회차 | 출연진 제안 | 코스튬·소품·액션 |
| --- | --- | --- |
| 1. 강의부터 결제해야 할까? | 치이카와·하치와레·쿠리만쥬·우사기 | 카디건·후드·니트, 우사기는 연노랑 후드와 목의 헤드폰. 결제 앞 망설임→예제 구조 보기→우사기가 글자 카드를 옮김→제목 수정 목표. 실제 수정 실습·성공은 2회로 넘김 |
| 2. 예제에서 문구 바꾸기 | 치이카와·시사·하치와레 | 후드·둥근 안경·메모장. 제목을 짚고, 메모하고, 수정 전후 비교 |
| 3. AI에게 부탁하는 방법 | 우사기·모몽가·하치와레 | 제작 조끼·베레모·펜. 성급한 요청→예상 밖 결과→수정 대상을 한 곳으로 좁힘 |
| 4. 움직임 붙이기 | 우사기·랏코·시사 | 작업 셔츠·타이머·스토리보드. 효과를 과하게 넣음→제목 등장 하나만 시범→읽을 시간 확인 |
| 5. 필요한 학습 선택하기 | 쿠리만쥬·치이카와·랏코, 마지막 단체 | 편한 니트·담요·체크리스트. 막힌 점 기록→다음 학습 선택→7종 단체 완성 축하 |

이 출연진은 초안이다. 행동이 명확한 대체 출연은 가능하며 캐릭터 수를 늘리기 위해 이야기와 무관한 인물을 끼워 넣지 않는다.

## 제작·QA 연결

치이카와 작업은 `--skill handdrawn-illustrations3`를 사용한다. request.md에 이 프로필 경로, 선택한 출연진, 각 장의 코스튬·액세서리·감정·액션, 원본 참고와 앵커의 경로·역할을 명시한다. 이미지 생성과 QA에는 실제 참고 파일을 함께 전달한다.

검수 항목: 캐릭터별 식별 특징, 의상 속에서도 유지되는 비율, 귀·꼬리 잘림, 출연진 중복·혼합, 소품 연속성, 감정과 액션의 의미, 대사 과밀, 성인 독자 상황과의 연결. 사용자 지정 캐릭터를 기본 프리셋으로 바꾸지 않는다. 이미지 생성·독립 QA·1080×1350 보정·회차별 100~500자 캡션은 기존 워크플로를 따른다.
