- S1 원문 대조 및 보완 목록 작성 — ✅ 계획대로 반영/주의/생략으로 구분
- S2 5장 사건형 콘티 작성 — ✅ 계획대로 장별 역할·행동·화면·정확 문구 포함

## 계획과 실제의 차이

- 유의미한 차이 없음.
- 본문 과밀도를 줄이기 위해 창업자 5명의 이름과 모든 매출을 장면에 나열하지 않고, 구체 수치는 2·3장의 작은 근거 카드와 문서 앞부분의 보완 사항에 배치했다.
- 원문 내부에서 AI Directories 월 매출이 서로 다르게 제시된 점은 단일 수치로 확정하지 않고 “월 1만 달러 안팎”으로 처리했다.
