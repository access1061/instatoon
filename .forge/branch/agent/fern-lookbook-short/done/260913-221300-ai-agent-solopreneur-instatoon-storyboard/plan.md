# AI 에이전트 코딩 시대의 1인 창업 원칙 인스타툰 콘티 초안

## 목표 / 제외 범위
- 목표: 제공 원고와 2026-09-12 블로그 원문을 대조해 누락된 근거를 보완하고, 비전공자도 이해할 수 있는 5장 판타지 파티 인스타툰 콘티 초안을 작성한다.
- 제외 범위: 이번 작업에서는 이미지 생성, 1080×1350 변환, 최종 게시 이미지 패키징을 하지 않는다.

## 기준 자료
- 용어집: 없음
- 관련 ADR: 없음
- 기준 원문: https://gyuha.com/post/2026/09/2026-09-12-five-ai-solopreneurs-distribution-first-playbook/
- 완료 정의: `assets/2026-09-13/ai-agent-solopreneur-instatoon-storyboard.md`에 ① 원문 대조 누락·보완 사항, ② 5장 콘티의 장별 정보 역할·감정 역할·캐릭터 행동·정확한 문구, ③ 과장 방지용 수치 기준일 고지와 비전공자용 용어 풀이, ④ 후속 이미지 생성에 바로 쓸 수 있는 화면 구성이 포함되어 있다.

## 작업 단위
- [ ] S1. 제공 원고와 원문을 대조해 빠진 구체 사례·수치와 상충 표현을 정리한다. — 완료 기준: 콘티 문서에 반영/주의/생략으로 구분된 보완 목록이 있다.
- [ ] S2. `착각 깨기 → 유통 우선 → 초소형 MVP → AI 에이전트 자동화 → 실행 체크리스트·리스크` 흐름의 5장 콘티를 작성한다. — 완료 기준: 각 장에 정보 역할, 감정 역할, 주도 캐릭터, 1~2개 상황 컷, 짧은 정확 문구가 모두 있다. (의존: S1)
- [ ] S3. 비전공자가 이해하기 어려운 용어를 일상어로 바꾸고 사실·수치·과밀도를 검수한다. — 완료 기준: MVP·유통·플랫폼 종속성·AI 에이전트를 쉬운 표현으로 풀고, 모든 매출 수치에 사례·기준일·성과 비보장 맥락이 붙어 있다. (의존: S2)
