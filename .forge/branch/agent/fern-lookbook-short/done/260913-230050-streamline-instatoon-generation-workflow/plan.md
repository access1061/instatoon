# 인스타툰 생성 빠른 워크플로우 구현

## 목표 / 제외 범위
- 목표: 이 워크스페이스에서 인스타툰 이미지 생성 요청을 받으면 별도 확인 없이 TDD를 `off`로 기록하고, 원고 분석·최소 콘티·이미지 생성·검수·1080×1350 변환·캡션 저장까지 가장 짧은 안전 경로로 이어지게 프로젝트 지침을 수정한다.
- 목표: 사용자가 기획만 요청했을 때는 콘티에서 멈추고, 이미지 생성을 요청했을 때만 생성 단계까지 자동 진행하도록 의도를 구분한다.
- 제외 범위: Forge 전체 플러그인이나 사용자 전역 설정은 바꾸지 않으며, 다른 워크스페이스에는 적용하지 않는다.

## 기준 자료
- 워크스페이스 라우팅: `AGENTS.md`
- 인스타툰 기본 절차: `skills/fantasy-party-insta-toon/SKILL.md`
- 이미지 생성 절차: 설치된 `imagegen` 스킬
- 관련 ADR: 없음
- 완료 정의: `AGENTS.md`와 필요한 경우 워크스페이스의 `skills/fantasy-party-insta-toon/SKILL.md`에 다음 규칙이 명시되고 서로 충돌하지 않는다. ① 이미지 산출물이 포함된 작업은 TDD를 자동 `off`로 확정해 TDD 질문을 생략한다. ② 장수·스타일·참고 이미지·정확 문구가 이미 있으면 추가 질문 없이 최소 콘티 후 즉시 생성한다. ③ 기획만 요청하면 생성하지 않는다. ④ 5장 이하는 내장 `image_gen`을 한 장씩 호출하고 첫 안정 결과를 연속성 앵커로 사용한다. ⑤ 한글·캐릭터·의미를 검사하고 1080×1350 최종본과 100~500자 캡션을 저장한다. ⑥ 실패나 필수 입력 누락만 사용자 확인 단계로 올린다.

## 작업 단위
- [ ] S1. 현재 `AGENTS.md`와 로컬 인스타툰 스킬의 중복·충돌·불필요한 확인 단계를 조사한다. — 완료 기준: 유지할 안전 게이트와 생략할 확인 질문의 경계가 정리된다.
- [ ] S2. 프로젝트 범위의 빠른 이미지 생성 라우팅 규칙을 구현한다. — 완료 기준: TDD 자동 off, 최소 콘티, 즉시 생성, 필수 입력 누락 시에만 질문하는 규칙이 실제 세션 시작 시 읽히는 파일에 반영된다. (의존: S1)
- [ ] S3. 대표 요청 세 가지로 라우팅을 문서 수준에서 검증한다. — 완료 기준: `원고+이미지 생성`, `콘티만 요청`, `필수 참고 이미지 누락`이 각각 생성 진행·콘티 종료·입력 요청으로 판별되고 기존 저장·QA 규칙이 유지된다. (의존: S2)
