# 스타일 DNA

## 한 줄

순백, 미니멀, 손그림, 여백, 절제, 기발함, 제품 스케치 감각, 한글 손글씨 느낌, 구조는 명확하되 설명서 같지 않게.

오랫동안 AI·제품·디자인·개발 도구를 다뤄온 사람이 흰 종이에 슥슥 그려낸 설명 스케치 한 장처럼.

## 반드시

- 16:9 가로형 본문 삽화.
- 순백 배경: 베이지, 따뜻한 회색, 종이 질감, 그라데이션, 그림자, 노이즈, 빈티지 종이 느낌 금지.
- 검은 손그림 선화 위주: 가는 선, 약간의 떨림, 기계적이지 않고 벡터스럽지 않으며 두꺼운 외곽선이 아님.
- 넉넉한 여백: 주체는 화면의 약 40%~60%, 최소 35% 빈 공간, 가급적 한 덩어리의 고요한 영역.
- 소량의 한글 손글씨 주석: 최대 5~8곳, 각 2~8자 내외.
- 한 그림은 하나의 핵심 동작·구조·상태·은유만.
- 구조는 자연스럽게 표현하고, 그림 위에 구조 유형 이름을 쓰지 않는다.

## 색상

- 검정: 주체 선화, 캐릭터, 테두리, 구조, 주요 글자, 핵심 사물.
- 빨강: 핵심 주석, 문제, 감정 포인트, 중요한 경고, 결과.
- 주황: 메인 흐름, 경로, 화살표, 자동화 방향, A에서 B로의 이동 관계.
- 파랑: 보충 설명, 머릿속 상태, 시스템 상태, 2차 설명, AI/어시스턴트/자동화 힌트.

파랑은 매 장마다 필수가 아니다. 색은 절제 — 많기보다 적게.

## 절대 금지

- 상업 일러스트 금지.
- PPT 인포그래픽 금지.
- 정식 흐름도 금지.
- 강의 슬라이드 금지.
- 귀여운 카툰 포스터 금지.
- 아동 일러스트 금지.
- 복잡한 아키텍처 다이어그램 금지.
- 정교한 플랫 일러스트 금지.
- 테크 감성 UI 금지.
- 실제 앱 스크린샷 금지.
- 복잡한 배경·그라데이션·그림자·질감 금지.
- 모든 노드를 일일이 설명하지 말 것.
- 좌측 상단에 "Workflow / 흐름도 / 시스템 아키텍처 / 흔한 함정 / 로드맵" 등 유형 제목 금지.

## 미감 방향

기발하고, 창의적이고, 흥미롭고, 깔끔하고, 자유분방하게.

귀엽거나, 유치하거나, 너무 복잡하거나, 뻣뻣하지 않게.
