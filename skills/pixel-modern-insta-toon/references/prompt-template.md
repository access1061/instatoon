# Prompt Template

Use one prompt per final image. Fill only the fields needed for the current task.

```text
Generate one standalone Korean modern pixel-art insta-toon image.

Format:
{1:1 square or 4:5 vertical unless otherwise requested}. Social-media-ready composition with enough margin for Korean text.

Visual style:
Cute modern pixel-art chibi toon. Crisp blocky pixel edges, limited warm palette, clustered square highlights, simplified shapes, clean readable silhouette. Soft cozy everyday mood. Not painterly, not realistic, not 3D, not smooth vector. The image should feel like a polished indie-game dialogue scene or sticker-like pixel webtoon panel.

Reference use:
Use assets/reference-dot-style.jpg only as a loose reference for pixel texture, chibi proportions, cozy compact composition, and small highlight clusters. Do not copy its characters, plant-on-head motif, fantasy styling, pose, scene, or exact colors.

Character:
Modern human chibi character with big head, small body, rounded human ears, simple face, understated expression.
Hair: {long hair / bob cut / tied hair / short hair / scene-appropriate variation}.
Clothing: {modern outfit such as hoodie, knit, shirt, cardigan, blazer, jeans, slacks, sneakers}.
Accessories: {glasses / cap / beanie / headset / backpack / laptop / smartphone / notebook / coffee / checklist / other scene-relevant accessories, max 1 to 3}.
The character must perform the core action: {checking / comparing / organizing / debugging / choosing / posting / warning / waiting / handing off}.

Theme:
{topic}

Core idea:
{one sentence explaining what this image must communicate}

Composition:
{single moment / before-after / choice / hidden cost / small loop / conversation beat}. Describe the panel layout and what happens in each panel.

Korean text to render exactly:
- Speech bubble 1: "{short Korean line or omit}"
- Speech bubble 2: "{short Korean line or omit}"
- Text overlay: "{1 to 2 short Korean lines or omit}"
- Small labels: "{label1}" / "{label2}" / "{label3 or omit}"

Constraints:
Do not add extra text. Keep Korean text short and readable. Do not copy or resemble any named anime, manga, game, webtoon, or celebrity character. No elf ears, pointed ears, fantasy robe, cape, armor, magic staff, spell effect, wings, horns, tail, or fantasy jewelry. Use modern clothing only. Accessories must support the situation. Keep the scene simple and not crowded.
```

## Text Stabilization

If the requested text is long, split the image into multiple panels or reduce text. Prefer:

- one short speech bubble
- one small label
- one short overlay

Avoid placing more than three Korean text areas in one image.
