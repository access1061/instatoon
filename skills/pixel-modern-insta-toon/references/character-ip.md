# Character IP

## Character System: Modern Pixel Chibi

Use a flexible cast of modern human chibi characters. The character is not fixed; adapt hair, clothing, expression, and accessories to the manuscript. Consistency comes from proportions, pixel rendering, and calm modern styling.

## Shape

- Big head, small body, short limbs.
- Simple rounded human ears only.
- Large simplified eyes or small sleepy eyes.
- Small mouth and understated expressions.
- Hands and feet are simplified pixel clusters.
- Hair is one of: long straight hair, bob cut, tied hair, short hair, soft bangs, or side-parted hair.

## Clothing

Use modern daily-life or workwear:

- knit, hoodie, sweatshirt, shirt, cardigan, blazer, denim jacket
- slacks, jeans, skirt, casual pants
- sneakers, loafers, simple boots

Outfit should support the scene. A work issue can use shirt/cardigan. A casual diary can use hoodie. A study scene can use knit and tote bag.

## Accessories

Accessories are allowed when they explain context. Use 1 to 3:

- glasses, cap, beanie, hairpin, headset, earbuds
- backpack, tote bag, badge, watch
- laptop, smartphone, tablet, notebook, pen, checklist
- coffee cup, calendar, sticky note, small plant, delivery box

Do not add accessories just for decoration. If removing the accessory does not weaken the meaning, omit it.

## Role

The character must perform the core action:

- checking a phone
- comparing two notes
- sorting cards
- debugging a laptop
- hesitating before a choice
- posting a finished image
- crossing out a risky option
- handing off a result
- waiting with a timer
- organizing a checklist

## IP Safety

The reference image can inform pixel texture, chibi scale, and cozy mood only. Do not copy:

- character identity
- exact hairstyle and color combination
- costume
- pose pair
- plant-on-head composition
- fantasy props
- franchise-specific mood markers

When a user asks for a named character style, convert it to an IP-safe description such as "quiet modern pixel chibi with calm expression and soft colors."
