# 플랫 일러스트 및 그래픽 (Flat Tech Illustration)

## 핵심 정의

만화 형태(말풍선, 만화 컷 구성)를 탈피하여, 글의 핵심 개념을 세련되게 요약하는 **단일 플랫 벡터 그래픽, 3D 렌더링, 또는 아트 일러스트**를 설계하고 생성한다.
SaaS 웹사이트나 테크 블로그에서 흔히 사용되는 고품질 그래픽 디자인 스타일을 모방한다.

## 참조 가이드

- `references/style-dna.md` — 지원하는 화풍(플랫 벡터, 3D 클레이, 감성 수채화 등)과 스타일 규칙.
- `references/prompt-template.md` — 화풍별 이미지 생성 프롬프트 템플릿.

## 워크플로우

1. **컨셉 정의:** 본문의 내용을 한 장의 세련된 이미지로 상징화할 개념(Metaphor)을 기획한다.
2. **화풍 선택:** 사용자의 요청이나 글의 분위기에 적합한 화풍(Flat Vector, 3D Clay, Watercolor)을 결정한다.
3. **텍스트 배제 설계:** 만화가 아니므로 말풍선을 제거하고, 텍스트가 꼭 필요한 경우 카드뉴스 표지처럼 깔끔한 타이틀 오버레이 형태로만 처리한다.
4. **이미지 생성:** 선택된 화풍의 DALL-E/image_gen 프롬프트 템플릿을 사용하여 고해상도로 1장 생성한다.
5. **저장:** `assets/YYYY-MM-DD/01-illustration-name.png` 형식으로 저장한다.
