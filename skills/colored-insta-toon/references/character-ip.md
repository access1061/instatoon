# 캐릭터 IP (Colored Insta Toon)

## 기본 정의
현대적인 일반 성인을 기반으로 하며, 큰 머리와 작은 몸의 미니 캐릭터(Chibi, Big-head small-body) 비율을 유지합니다. 
성별과 직업은 원고 내용에 따르되, 다음 고정 컬러 배색 규칙을 적용해 캐릭터의 컷 간 일관성을 확보합니다.

## 캐릭터 컬러 프로필

### 1. Momo (여성 캐릭터 기본형)
- **외형:** 귀여운 단발머리(Bobbed hair), 동그란 눈.
- **채색 가이드:**
  - Hair: Muted brown (#6E5042)
  - Skin: Light beige skin (#FFF1E6)
  - Clothes (Top): Pastel lemon yellow (#FFF9D0) 또는 Soft coral pink (#FFD2D2)
  - Clothes (Bottom): Light gray slacks (#D3D3D3) 또는 Denim blue (#8DA3C4)
  - Shoes: Plain white sneakers

### 2. Kkami (남성 캐릭터 기본형)
- **외형:** 단정한 숏컷 머리(Neat short hair), 둥근 안경 착용.
- **채색 가이드:**
  - Hair: Charcoal dark gray (#333333)
  - Skin: Light beige skin (#FFF1E6)
  - Clothes (Top): Muted mint blue (#BCE3C5) 또는 Warm beige (#E8DCC4)
  - Clothes (Bottom): Charcoal gray jeans (#555555)
  - Shoes: Plain black sneakers

## 절대 금지
- 판타지 귀(엘프 귀), 마법 장신구, 비현실적인 머리색(핑크, 네온그린 등) 금지.
- 매 컷마다 캐릭터 옷 색상이 바뀌는 것 금지. 프롬프트에 고정 색상 코드를 묘사해 줄 것.
