# 사용자 의도 우선 인스타툰

## 우선순위

다음 순서로 결정한다.

1. 사용자의 명시 지시: 장수, 비율, 색, 캐릭터, 분위기, 텍스트.
2. 첨부·지정한 참고 이미지: 선, 채색, 비율, 표정, 구도, 캐릭터 특징.
3. 원고의 핵심 주장과 감정 흐름.
4. 지시와 참고가 없을 때만 `references/style-dna.md`의 기본값.

참고 이미지가 있으면 실제 이미지 입력으로 전달한다. 기존 프리셋을 이유로 사용자의 스타일을 약화하거나 반대 특성을 추가하지 않는다. 특정 요소만 참고하라는 요청도 그대로 따른다.

## 간결한 생성 플로우

### 1. 읽기

원고에서 핵심 메시지와 감정 전환을 찾고, 참고 이미지가 있으면 재현할 시각 특징 3~6개를 추출한다. 사실·숫자·고유명사는 원고와 일치시키며 불확실한 내용을 임의로 보강하지 않는다.

### 2. 장면 정하기

- 사용자가 지정한 장수와 비율을 우선한다.
- 핵심 메시지 하나면 1장으로 바로 진행한다.
- 문제·원인·전환·결론이 나뉘거나 한 장이 과밀하면 2~5장으로 나눈다.
- 각 장은 `역할 / 핵심 의미 / 캐릭터 행동 / 정확한 문구`만 짧게 정한다.
- 사용자가 기획만 요청했을 때만 shot list를 보여준다. 생성 요청이면 불필요한 확인 없이 진행한다.

자세한 기준은 `references/forge-routing.md`를 필요할 때만 읽는다.

사용자가 에피소드형 정보툰, 재미있는 정보툰, 고정 캐릭터의 사건 전개를 요청하면 `references/episode-toon.md`도 읽는다. 이때 여러 장을 문제 → 욕망/오해 → 반전/판단 → 해결/콜백으로 묶고, 캐릭터 시트와 각 장의 정보 역할·감정 역할을 내부적으로 고정한다. 특정 작품이나 캐릭터는 복제하지 않는다.

### 3. 한 장씩 생성하기

`image_gen`으로 각 장을 따로 생성한다. 프롬프트는 `references/prompt-template.md`를 사용하되, 사용자 지시와 참고 이미지 분석으로 변수를 채운다.

- 캐릭터가 여러 장에 반복되면 첫 안정 결과나 캐릭터 참조를 다음 장에도 함께 전달한다.
- 정확한 한글은 `Text to render exactly:` 아래에 짧게 명시한다.
- 스타일 적합성이 중요한 첫 생성은 텍스트와 소품을 줄여 스타일 앵커로 만들 수 있다.
- 인스타 피드·캐러셀은 생성 프롬프트에 `exact 4:5 portrait, 1080x1350`을 명시한다. 단, 모델의 비율 지시 준수를 신뢰하지 말고 패키징 단계에서 실제 픽셀을 검사한다.
- 에피소드형 요청에서는 고정 캐릭터의 특징을 매 장 반복하고, 설명 라벨보다 행동·표정·짧은 반응으로 정보를 전달한다.

### 4. 확인하고 고치기

`references/qa-checklist.md`에서 사용자 의도, 캐릭터 일관성, 핵심 의미, 한글, 과밀도만 확인한다. 가장 가까운 결과가 있으면 처음부터 다시 만들기보다 그 이미지를 부분 편집한다.

### 5. 패키징하기

최종 이미지를 `assets/YYYY-MM-DD/`에 `01-topic-name.png` 형식으로 저장한다. 같은 이름이 있으면 `-v2`, `-v3`을 붙이고 기존 결과를 보존한다.

인스타 피드·캐러셀 결과는 저장 전에 `scripts/fit_instagram_4x5.py`를 실행해 정확히 `1080×1350`으로 만든다. 원본 전체를 비율 유지 축소하고 부족한 영역만 흰색 여백으로 채운다. 자르기, 늘이기, 말풍선 재배치는 하지 않는다. 변환 후 크기가 `1080×1350`인지 다시 검사하며, 이 검사를 통과한 파일만 최종본으로 전달한다.

이미지 생성이 끝나면 별도 요청이 없어도 `references/caption-template.md`에 따라 100~500자의 인스타 캡션을 작성한다. 500자를 채우지 말고 내용을 충분히 전달하는 가장 짧은 길이를 선택한다. 그림 속 대사를 반복하기보다 이미지에서 생략한 배경, 사용법, 핵심 수치, 한계와 주의점을 보완한다. 캡션은 이미지와 함께 전달하고 `instagram-caption-{topic}.md`로 같은 날짜 폴더에 저장한다.

전달할 때 이미지 경로, 캡션, 선택적 수정 후보만 짧게 알린다.

- 다장 라우팅이 필요할 때: `references/forge-routing.md`

- 생성 프롬프트: `references/prompt-template.md`
- 생성 후 검사: `references/qa-checklist.md`
- 게시용 캡션 작성: `references/caption-template.md`
- 인스타 4:5 무손실 패딩: `scripts/fit_instagram_4x5.py`
