# 스타일 DNA

## 한 줄

순백, 미니멀, 검은색 얇은 사인펜 선화, 넓은 여백, 현대 미니 캐릭터, 짧은 만화 컷, 채색 없음.

`assets/sample-line-style.png`와 `assets/sample-line-style-2.png`는 선의 감각과 3컷 구성만 참고한다. 샘플의 판타지 소재, 엘프 귀, 망토, 장신구, 세계관은 금지한다.

## 반드시

- 16:9 가로형 본문 삽화.
- 순백 배경: 베이지, 회색, 종이 질감, 그라데이션, 그림자, 노이즈 금지.
- 검은색 얇은 사인펜 선화.
- 손으로 가볍게 그린 듯한 약간 흔들리는 선.
- 선 굵기는 완전히 일정하지 않게.
- 샘플 2장처럼 머리카락과 손은 짧은 반복 펜선으로 정리한다.
- 샘플 2장처럼 큰 머리, 작은 몸, 작은 손발의 미니 캐릭터 비율을 유지한다.
- 샘플 2장처럼 가로로 넓은 3컷 흐름과 넉넉한 컷 간격을 선호한다.
- 채색 없음. 명암, 그라데이션, 3D 효과 금지.
- 넉넉한 여백: 주체는 화면의 약 40%~60%, 최소 35% 빈 공간.
- 본문의 핵심을 1~3개의 작은 상황 컷으로 구성.
- 한글 말풍선과 텍스트 오버레이는 원고의 핵심 내용 전달에 필요하면 사용한다.
- 짧은 손글씨 주석은 필요할 때만 2~6자 단어로 사용한다.
- 캐릭터가 확인, 비교, 정리, 경고, 선택, 기록, 해결 중 하나 이상의 행동을 직접 수행.

## 텍스트

- 제목을 쓰지 않는다.
- 구조 유형 이름을 쓰지 않는다.
- gpt image-gen에서는 한글 말풍선, 텍스트 오버레이, 짧은 주석을 생성 단계에서 이미지 안에 직접 넣는다.
- 말풍선은 한 문장 이하로 짧게 쓴다.
- 텍스트 오버레이는 1~2줄 중심으로 쓴다.
- 짧은 주석은 단어 중심: 예) 확인, 비교, 정리, 위험, 선택, 기록, 보류, 중요.
- 후처리 조판은 사용자가 요청하거나 생성 결과의 한글이 실제로 깨졌을 때만 사용한다.

## 절대 금지

- 엘프 귀, 뾰족귀, 요정, 마법사, 판타지 종족.
- 판타지 의상, 망토, 갑옷, 마법 소품, 보석 장신구.
- 상업 일러스트, PPT 인포그래픽, 정식 흐름도, 강의 슬라이드.
- 컬러 웹툰 키비주얼, 아동 일러스트, 과한 귀여움.
- 복잡한 배경, 실제 UI 스크린샷, 테크 감성 UI.
- 벡터처럼 완벽하게 매끈한 선.

## 미감 방향

노트에 직접 그린 짧은 현대 만화 컷처럼 보이게 한다. 단순하고 편안하지만, 장면만 봐도 글의 핵심 구조가 이해되어야 한다.
