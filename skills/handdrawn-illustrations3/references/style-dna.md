# 스타일 DNA

## 원칙

스타일은 고정 금지 목록이 아니라 사용자 의도를 번역한 생성 명세다. 다음 순서로 정한다.

1. 사용자가 직접 말한 스타일.
2. 참고 이미지에서 관찰한 스타일.
3. 원고 분위기에 맞는 선택.
4. 정보가 없을 때만 기본 스타일.

## 참고 이미지 분석

이미지를 실제로 보고 다음 중 눈에 띄는 특징 3~6개만 추출한다.

- 선: 얇음/굵음, 손그림/디지털, 각짐/둥글음.
- 색: 흑백/플랫/파스텔/고채도, 명암과 하이라이트.
- 캐릭터: 머리·몸 비율, 눈·입·손발, 실루엣, 의상과 종족 특징.
- 감정: 차분함, 장난스러움, 과장, 긴장, 따뜻함.
- 구도: 가로/세로, 컷 분할, 겹침, 원근, 여백.
- 표면감: 노트 스케치, 잉크, 수채화, 애니메이션 셀, 3D 등.

사용자가 “스타일만” 참고하라고 하면 원본의 인물·의상·정확한 포즈는 복제하지 않는다. 사용자가 캐릭터 자체를 반영해 달라고 하면 보이는 특징을 구체적으로 기록해 유지한다.

## 기본 스타일

지시와 참고 이미지가 없을 때만 사용한다.

- 16:9 가로형.
- 순백 배경과 넉넉한 여백.
- 검은색 얇은 사인펜 선화.
- 큰 머리와 작은 몸의 미니 캐릭터.
- 1~3개의 짧은 상황 컷.
- 필요한 경우 짧은 한글 말풍선과 주석.

기본값은 언제든 사용자 지시나 참고 이미지로 교체할 수 있다.
