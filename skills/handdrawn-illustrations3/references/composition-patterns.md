# 구도 패턴과 원본 규칙

## 기본 구조 유형

하나만 선택한다. 너무 섞지 않는다.

### Workflow 흐름

적합: 입력 → 처리 → 출력, 콘텐츠 생산, AI 워크플로우, 자동화 체인.

그리는 법: 왼쪽에 입력, 가운데에 캐릭터 또는 기이한 기계가 처리, 오른쪽에 출력, 주황색 화살표로 메인 흐름.

### 시스템 국부

적합: 정보원, 필터, 데이터베이스, 렌더러, 에이전트 시스템 일부.

그리는 법: 핵심 모듈 3~5개만, 캐릭터는 그중 하나의 핵심 동작에 참여.

### 전후 대비

적합: 혼란/질서, 수동/자동, 분산/수렴, 불안/안정.

그리는 법: 왼쪽 혼란, 오른쪽 안정, 가운데 주황 화살표. 캐릭터는 더 과장 가능.

### 역할 상태

적합: 사용자 페인포인트, 창작자 상태, 도구 과잉, 정보 불안, 막힘에서 굴러감으로.

그리는 법: 작은 상태 2~4개, 각 상태에 짧은 주석 하나.

### 개념 은유

적합: 콘텐츠 공장, 정보 창고, 머릿속 블랙박스, 워크플로우 기계, 자동 리포트.

그리는 법: 큰 기이한 사물 또는 기계 하나, 소량의 입력, 하나의 출력. 기억에 남게.

### 방법 계층

적합: 방법론 프레임워크, 시스템 계층, 능력 스택, 콘텐츠 시스템 계층.

그리는 법: 층층이 쌓인 상자, 정식 피라미드 금지. 캐릭터는 옆에서 벽돌 나르기나 조립.

### 지도 경로

적합: 아이디어에서 출시까지, 사용자 여정, 콘텐츠 이어받기 경로, 학습 로드맵.

그리는 법: 굽은 경로 하나, 소량의 노드, 캐릭터가 줄을 끌거나 걸어감.

### 짧은 만화 컷

적합: 실패에서 성공, 실제 과정, 푸념, 사용 전후 변화.

그리는 법: 작은 장면 2~4개, 각 칸은 하나의 동작만.

## 원본 은유 생성법

매번 현재 글에서 은유를 새로 발명한다. 옛 그림을 베끼지 않는다.

### 3단계

1. 추상 개념을 물리적 동작으로 치환: 막힘, 빠뜨림, 무거워짐, 분류, 가라앉음, 발효, 문 열기, 접기, 풀기, 역류.
2. 시스템 구조를 로테크 사물로 치환: 고장 난 기계, 종이상자, 서랍, 수도관, 우체통, 기이한 다이얼, 저울, 우물, 사다리, 이상한 작업대.
3. 캐릭터가 동작을 수행: 옆에 서지 말고, 기계에 끼이거나 줄을 잘못 당기거나 문을 지키거나 나르거나 수선하거나 무게를 달거나 사다리를 잡거나 기록하거나 어떤 기이한 장치에 무언가를 밀어 넣는다.

### 사용 가능한 사물 풀

- 종이상자, 서랍, 낡은 기계, 깔때기, 저울, 우체통, 문, 우물, 사다리, 수도관, 실타래, 수문, 회전판, 블랙박스, 펀치기, 제면기, 빨랫줄, 기이한 작업대.
- 쓸 때 1~2개만 고른다. 가득 채우지 않는다.

### 캐릭터 동작 풀

- 당기기, 메기, 밀어넣기, 건지기, 누르기, 무게 달기, 꿰매기, 자르기, 비틀기, 지키기, 밀기, 받기, 풀기, 표시하기, 회수하기.
- 동작은 핵심 의미에 복무해야 한다. 기이함을 위한 기이함은 금지.

## 복제 금지 규칙

같은 주제라도 새 은유로 바꾼다. 예: "이어받는 경로"를 꼭 길로 그릴 필요 없다 — 캐릭터가 콘텐츠 꼬리를 문고리에 거는 식으로. "하나로 여러 용도"를 꼭 물고기로 그릴 필요 없다 — 캐릭터가 종이 뭉치 하나를 여러 형태로 눌러 찍는 식으로.
