# 인스타 캡션

이미지 생성이 끝나면 게시용 캡션까지 한 묶음으로 작성한다.

## 기준

- 전체 길이는 공백 포함 100~500자다. 500자를 목표로 채우지 않는다.
- 원고의 정보량에 맞춰 핵심이 충분히 전달되는 가장 짧은 길이를 선택한다.
- 단순한 주제는 100~250자, 보충 설명이 필요한 주제는 250~400자, 수치·제약·주의가 많은 주제만 400~500자를 사용한다.
- 첫 1~2문장으로 호기심을 이어간다.
- 그림의 대사를 그대로 요약하지 말고 그림에서 빠진 사실·수치·설정법·활용 예를 보충한다.
- 중요한 한계, 시점, 대상 범위, 오해 가능성을 명확히 쓴다.
- 마지막에 짧은 활용 제안이나 질문을 넣는다.
- 해시태그까지 포함해 500자를 넘지 않으며 관련도 높은 3~8개만 붙인다.
- 금융·의료·법률 등 고위험 주제는 필요한 고지 문구를 포함한다.
- 원고에 없는 사실을 임의로 만들지 않는다.

## 형식

```text
{호기심을 잇는 도입 1~2문장}

{이미지에서 생략된 작동 원리·설정법·핵심 정보}

{한계 또는 주의점 + 실제 활용 제안}

{짧은 행동 유도 또는 질문}

#{핵심태그} #{관련태그} ...
```

이미지와 캡션은 항상 함께 전달하고, 캡션을 `assets/YYYY-MM-DD/instagram-caption-{topic}.md`에도 저장한다. 동일 이름이 있으면 버전 접미사를 붙인다.
