# 간결한 라우팅

## 결정

- 장수·비율·스타일을 사용자가 지정하면 그대로 우선한다.
- 핵심 메시지가 하나면 1장으로 즉시 생성한다.
- 문제·원인·전환·결론 중 둘 이상이 독립적이면 2~5장으로 나눈다.
- 말풍선, 인물, 소품이 과밀하면 내용을 줄이거나 장수를 늘린다.
- 금융·기술·정책 등 정확성이 중요한 원고는 생성 전에 숫자·고유명사·인과관계를 원고와 대조한다.

## 내부 장면 계획

사용자가 생성까지 요청했다면 긴 설명 대신 다음만 내부적으로 정하고 바로 진행한다.

```text
장 번호 | 역할 | 핵심 의미 | 캐릭터 행동 | 정확한 문구
```

사용자가 shot list나 기획안을 요청했을 때만 이를 먼저 보여준다.

## 실행

```text
Plan → Generate → Check → Save
```

- Plan: 핵심과 참고 스타일을 장면별로 고정한다.
- Generate: 참고 이미지를 실제 입력으로 넣고 한 장씩 생성한다.
- Check: 의도·캐릭터·의미·한글만 검사하고 가까운 결과를 편집한다.
- Save: 버전이 있는 파일명으로 저장하고 결과를 짧게 보고한다.
