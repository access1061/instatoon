# 캐릭터 지침

## 사용자 캐릭터 우선

사용자가 제공한 캐릭터 이미지와 설명을 최우선으로 반영한다. 사람, 동물, 판타지 종족, 로봇, 마스코트 등 형식을 미리 제한하지 않는다.

참고 이미지에서 다음을 짧게 기록한다.

- 머리와 몸의 비율 및 전체 실루엣.
- 머리 모양·색, 눈·귀·입의 형태.
- 피부·의상·소품과 고정 색상.
- 선화, 채색, 표정 강도.
- 반복해서 유지할 특징 3~5개.

## 시리즈 일관성

첫 장의 안정적인 캐릭터를 스타일 앵커로 저장하고 이후 장에 참조 이미지로 다시 전달한다. 장면마다 바뀌어야 하는 포즈·표정·의상은 사용자 지시에 따르고, 고정 특징은 유지한다.

캐릭터가 핵심 행동이나 감정을 보여주게 한다. 사용자가 장식적·키비주얼 구도를 원하면 그 의도를 우선한다.

여러 장의 에피소드형 툰에서는 이름과 역할, 실루엣, 얼굴·머리, 의상·색상, 대표 소품, 성격의 결함, 반복 표정이나 습관을 먼저 고정한다. `same character`라고만 쓰지 말고 각 장의 프롬프트에 고정 특징을 다시 명시한다. 사용자 캐릭터가 없을 때만 현대적인 성인 미니 캐릭터를 기본으로 만들며, 기억 가능한 특징 3개를 둔다.

## 캐릭터 카드

필요할 때만 아래 형식으로 정리한다.

```text
이름/역할:
실루엣과 비율:
얼굴·머리·귀:
색상과 의상:
대표 소품:
성격·반복 행동:
반드시 유지할 특징:
장면별 변경 가능 요소:
```

## 에피소드형 기본값

사용자가 별도 캐릭터를 주지 않고 에피소드형 정보툰을 요청했을 때만 적용한다.

- 큰 머리와 작은 몸의 현대적인 성인 미니 캐릭터.
- 단순하지만 서로 대비되는 평상시·위기 표정.
- 스마트폰, 노트북, 메모지 등 핵심 행동을 돕는 현대적 소품 1~3개.
- 확인, 비교, 정리, 경고, 선택, 기록, 해결 중 하나를 캐릭터가 직접 수행.
- 특정 유명 인물·캐릭터·작품의 고유 외형, 의상, 소품은 복제하지 않음.

사용자 지시나 참고 이미지가 이 기본값과 다르면 사용자 의도를 따른다.
