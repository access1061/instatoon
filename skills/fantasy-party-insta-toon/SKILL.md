# 판타지 파티 인스타툰

## 범위

한국어 정보 원고를 3~5장의 컬러 4:5 캐러셀로 만든다. 세 명의 고정 파티가 질문하고 설명하고 반응하는 짧은 사건으로 정보를 전달하고, 게시용 인스타 원고까지 함께 패키징한다.

기존 `handdrawn-illustrations3`과 구분한다. 판타지 3인 파티의 외형·역할·감정 문법을 반복하는 요청에만 이 스킬을 사용한다. 사용자가 다른 캐릭터나 스타일을 명시하면 그 지시를 우선한다.

## 먼저 읽기

- 캐릭터와 화면 문법은 `references/visual-dna.md`를 읽는다.
- 장별 원고와 게시 원고는 `references/story-caption.md`를 읽는다.
- 이미지 생성 직전에는 `references/prompt-template.md`를 읽는다.
- 생성 후에는 `references/qa-checklist.md`로 검사한다.

## 작업 흐름

### 1. 원고 분석

핵심 주장, 독자가 처음 품을 질문, 작동 원리, 사용 절차, 제한·주의점을 추출한다. 원고에 없는 숫자·고유명사·인과관계는 만들지 않는다.

### 2. 캐러셀 설계

사용자가 장수를 정하면 그대로 따른다. 지정이 없으면 다음을 기본으로 한다.

- 3장: 질문 → 원리/절차 → 결론.
- 4장: 호기심 → 이유 → 설정/활용 → 제한과 반전.
- 5장: 호기심 → 원리 → 절차 → 활용 → 제한과 결론.

각 장은 `정보 역할 / 감정 역할 / 주도 캐릭터 / 정확한 문구`만 정한다. 생성 요청이면 shot list를 길게 보여주지 말고 바로 진행한다.

### 3. 이미지 생성

`image_gen`으로 한 장씩 따로 생성한다. 저장소의 기존 시리즈를 이어 달라는 요청이면 `assets/2026-08-13/instagram-4x5/`의 네 이미지를 실제 참고 이미지로 전달한다. 첫 안정 결과도 다음 장의 캐릭터·선·채색 앵커로 다시 전달한다.

- 정확한 4:5 세로형 구도를 요청한다.
- 세 캐릭터의 고정 특징을 매 장 반복한다.
- 한 장을 1~2개의 큰 상황 컷으로 구성한다.
- 말풍선은 감정·질문·판단을, 도표와 오버레이는 사실을 담당하게 한다.
- 프롬프트의 `Text to render exactly:` 아래에 짧은 한글 문구를 적는다.
- 요청하지 않은 제목, 로고, 문구를 추가하지 않는다.

### 4. 확인과 수정

가장 가까운 결과가 있으면 전체 재생성보다 부분 편집한다. 캐릭터가 달라지면 첫 안정 이미지와 고정 특징을 다시 전달한다. 한글이 틀리면 문구를 줄여 한 번 재생성하고, 계속 틀리면 해당 영역을 부분 편집한다.

### 5. 패키징

원본을 보존하고 최종본을 `assets/YYYY-MM-DD/`에 `01-topic-name.png` 형식으로 저장한다. 같은 이름이 있으면 `-v2`, `-v3`을 붙인다.

인스타 최종본은 `scripts/fit_instagram_4x5.py`로 정확히 `1080×1350`에 맞춘다. 자르거나 늘이지 않고 비율 유지 축소 후 흰 여백만 추가한다. 크기 검사를 통과한 파일만 전달한다.

별도 요청이 없어도 100~500자의 게시 원고를 작성해 `instagram-caption-{topic}.md`로 같은 날짜 폴더에 저장한다. 최종 보고에는 이미지 경로, 캡션 경로, 선택적 수정 후보만 짧게 포함한다.
