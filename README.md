## 💡 개요

본 워크스페이스는 개발, 기술 문서, 금융/정책, Vibe Coding, 릴리즈 노트 등 다양한 한글 원고를 바탕으로 **핵심 주장과 감정 흐름, 시각적 앵커(Cognitive Anchor)**를 추출하여 미니 캐릭터 기반의 인스타툰과 삽화를 신속하게 제작할 수 있도록 설계되었습니다.

- **간결한 생성 루프**: `Read ➔ Plan ➔ Generate ➔ Check ➔ Save`로 원고 분석부터 저장까지 처리.
- **이미지 생성 통합 한글 렌더링**: 후처리 조판 없이 `gpt image-gen` 생성 시점에 한글 말풍선과 설명 문구를 완성도 높게 일체화.
- **참고 이미지 우선**: 사용자가 지정한 캐릭터·선·색·비율·구도를 고정 프리셋보다 우선 반영.

## 🔥 주요 기능

- **자동 원고 라우팅 (Auto Routing)**:
  - **1장 단편 원고**: 확인 질문 없이 바로 생성.
  - **다컷 / 정보 집약 원고**: 짧은 내부 장면 계획을 만든 뒤 2~5장을 한 장씩 생성.
- **사용자 맞춤 디자인 스타일**:
  - 참고 이미지에서 선화, 채색, 캐릭터 비율, 표정, 구도를 추출해 반영.
  - 별도 지시가 없을 때만 순백 배경과 검은 사인펜 미니 캐릭터를 기본값으로 사용.
- **한글 말풍선 & 오버레이 최적화**:
  - 컷당 1문장 중심의 말풍선과 1~2줄 오버레이 텍스트로 정보과밀(Overcrowding) 방지.

## 📥 설치 및 설정

### Codex 전역 스킬 등록

로컬 Codex 환경에서 스킬을 바로 활용할 수 있도록 전역 스킬 경로(`$env:USERPROFILE\.codex\skills\`)로 복사합니다.

PowerShell을 열고 프로젝트 루트에서 아래 스크립트를 실행합니다:

```powershell
.\scripts\install-skills.ps1
```

## 🚀 사용 방법

### 1. 인스타툰 생성 요청 (기본)

Codex 프롬프트에 작성하고자 하는 원고와 함께 요청합니다:

```text
아래 원고를 인스타툰으로 작성해줘.

[원고]
최근 생성형 AI 기술의 발전으로 '바이브 코딩(Vibe Coding)'이 주목받고 있습니다.
하지만 코드 검증 없이 빠른 데모 개발에만 치중할 경우 maintenance 부채가 누적될 수 있습니다.
...
```

### 2. 생성 과정

1. **Read**: 원고 핵심과 참고 이미지의 시각 특징을 추출.
2. **Plan**: 장별 역할, 핵심 의미, 캐릭터 행동, 정확한 문구를 간단히 정의.
3. **Generate**: 참고 이미지를 전달하고 한 장씩 이미지 생성.
4. **Check**: 사용자 의도, 캐릭터 일관성, 한글, 정보 밀도를 검증하고 필요한 부분만 편집.
5. **Save**: 버전 파일명으로 저장하고 결과 보고.

## 🖼️ 결과물 저장 및 관리 규칙

- 생성된 이미지는 날짜별 자산 디렉터리에 저장됩니다:
  ```text
  assets/YYYY-MM-DD/
  ```
- 파일명 규칙:
  ```text
  assets/2026-07-19/01-vibe-coding-15min-dream.png
  assets/2026-07-19/02-vibe-coding-gap.png
  ```
- 동일 파일명이 존재할 경우 덮어쓰지 않고 `-v2`, `-v3` 등 버전을 지정하여 기존 자산을 보존합니다.
